# dsa-learn-digest 課綱：目標 = 有 Java 基礎，系統性學會資料結構與演算法，能應對技術面試與 LeetCode 中等題
# 一行一主題，# 為註解/分章。每天教「目前主題的下一小步」，主題走完才換下一行。
# 想跳過某主題，直接把那行刪掉或加 # 註解掉即可。

# ── M1 基礎心法：複雜度與陣列 ──
Big-O 複雜度：怎麼估一段程式的快慢
陣列 Array 與動態陣列 ArrayList：連續記憶體的代價與好處
字串 String：不可變性、StringBuilder 與常見操作
雙指標 Two Pointers：一次掃描解決兩層迴圈的事
滑動視窗 Sliding Window：子陣列/子字串問題的萬用框架

# ── M2 雜湊與基本結構 ──
HashMap / HashSet：O(1) 查找的原理與代價
前綴和 Prefix Sum：區間總和問題的預處理思維
Stack 堆疊：後進先出與括號配對、單調堆疊
Queue 佇列與 Deque：先進先出、雙端佇列的應用

# ── M3 鏈結串列 ──
Linked List 基礎：節點、指標與 dummy head 技巧
快慢指標：找中點、判斷環
反轉鏈結串列與經典變形

# ── M4 二分搜尋 ──
Binary Search 基礎：邊界條件寫對的固定套路
二分搜尋變形：找左界/右界、旋轉陣列
答案空間二分：對「答案」而不是「索引」二分

# ── M5 樹 ──
Binary Tree 基礎：遞迴思維與三種 DFS 走訪
BFS 層序走訪：Queue 怎麼配合樹用
Binary Search Tree：中序走訪的有序性
樹的經典題型：深度、直徑、最近共同祖先 LCA

# ── M6 堆與優先佇列 ──
Heap / PriorityQueue：Top-K 問題的標準解法

# ── M7 回溯與遞迴 ──
遞迴思維總整理：把問題交給「更小的自己」
Backtracking 回溯：排列、組合、子集的模板

# ── M8 圖 ──
圖的表示法：鄰接表與走訪基礎
圖的 DFS / BFS：連通塊、島嶼問題
拓撲排序 Topological Sort：有依賴關係的排程
最短路徑入門：BFS 解無權圖、Dijkstra 概念

# ── M9 動態規劃 ──
DP 入門：從遞迴加記憶化到列表格
一維 DP：爬樓梯、打家劫舍套路
二維 DP：網格路徑、背包問題概念
字串 DP：LCS 與編輯距離

# ── M10 收尾：貪心與面試整合 ──
Greedy 貪心：什麼時候可以貪、怎麼說服面試官
排序與區間問題：會議室、合併區間套路
面試解題流程總整理：從讀題到說出複雜度
