## 陣列上的掃描技巧：雙指標、滑動視窗、前綴和 · 第 1 步

### Two Pointers（雙指標）：相向而行

想像一個排好序的書架，找兩本厚度加起來剛好是某個數字的書。笨方法是一本一本試、每次都重新掃過整排書架；聰明的做法是找兩個人，一個從最左邊、一個從最右邊，兩人同時往中間走。這兩個人的位置就是程式裡的「指標（pointer）」——記著陣列（array）目前看到哪一格的變數。雙指標就是同時維護兩個這樣的位置，讓它們互相配合移動。

### 暴力解為什麼慢

找「陣列裡有沒有兩個數字加起來等於目標值」，直覺寫法是兩層迴圈：外層固定一個數字，內層再把整個陣列重新掃一遍。外層跑 n 次、內層每次又跑 n 次，總共 n×n 次，時間複雜度 O(n²)。雙指標讓左右兩根指標各自只從頭到尾走一趟，時間複雜度降到 O(n)。

### 相向指標怎麼移動

前提：陣列已排序（sorted）。左指標 left 從最左邊、右指標 right 從最右邊出發：

1. 把 left 與 right 指到的數字相加，跟目標值比較
2. 和剛好等於目標值 → 找到答案
3. 和太小 → 需要更大的數字 → left 右移一格
4. 和太大 → 需要更小的數字 → right 左移一格
5. 重複直到 left 與 right 相遇

⚠ 這套移動規則只有在陣列已排序的前提下才保證正確，未排序的陣列不能直接套用。

```java
public int[] twoSum(
    int[] nums, int target) {
  int l = 0;
  int r = nums.length - 1;
  // 左右指標相向靠近
  while (l < r) {
    int sum = nums[l] + nums[r];
    if (sum == target) {
      return new int[]{
          l + 1, r + 1};
    } else if (sum < target) {
      l++;
    } else {
      r--;
    }
  }
  return new int[]{-1, -1};
}
```

### 這東西用在哪

- 對寫程式的人：已排序陣列上的配對問題，優先考慮雙指標，比 hashmap 省一份 O(n) 的額外空間；用在未排序陣列上則邏輯不成立。
- 對產品端的人：已排序清單上的「找兩筆加總符合條件」功能，執行時間會隨資料量等比例增加、不會暴增；但若清單本身沒排序，先排序那一步可能才是真正瓶頸。

### LeetCode 練習

[#167 Two Sum II - Input Array Is Sorted](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/)（Medium）

給已排序的整數陣列 numbers 與目標值 target，找出兩個數字相加等於 target 的位置（1-based index）。

解法步驟：

1. left 指向陣列開頭、right 指向陣列結尾
2. 相加比較，等於 target 直接回傳
3. 太小則 left 右移，太大則 right 左移
4. 重複直到相遇

複雜度：時間 O(n)（左右指標合計最多各走一輪，不重複掃描）；空間 O(1)（只用兩個指標變數）。

```java
public int[] twoSum(
    int[] numbers, int target) {
  int l = 0;
  int r = numbers.length - 1;
  // 相向移動直到找到答案
  while (l < r) {
    int sum =
        numbers[l] + numbers[r];
    if (sum == target) {
      return new int[]{
          l + 1, r + 1};
    } else if (sum < target) {
      l++;
    } else {
      r--;
    }
  }
  return new int[]{-1, -1};
}
```

### 今日術語表

- **Two Pointers（雙指標）**：用兩個變數各記著陣列裡一個位置，配合移動取代重複掃描。
- **Opposite Direction（相向雙指標）**：兩根指標從陣列頭尾出發，往中間靠近直到相遇。
- **Sorted Array（已排序陣列）**：數字已排好序的陣列，是相向雙指標移動規則成立的前提。
- **Time Complexity（時間複雜度）**：描述資料量變大時執行時間如何變化的指標，例如 O(n²) 對 O(n)。
