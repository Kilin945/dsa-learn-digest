## 平衡樹 AVL：BST 為什麼會退化、旋轉怎麼救回來 · 第 2 步

### Right Rotation（右旋）

![右旋操作步驟](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/avl_tree.assets/avltree_right_rotate_step1.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

從底往上找，第一個平衡因子絕對值大於 1 的節點就是失衡節點（記為 node），它的左子節點記為 child。對 node 做右旋後，子樹恢復平衡，且仍保持二元搜尋樹的性質。

![有 grand_child 的右旋操作](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/avl_tree.assets/avltree_right_rotate_with_grandchild.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

當 child 有右子節點 grand_child 時，要多一步：把 grand_child 改掛成 node 的左子節點，否則那塊子樹會遺失。

#### 重點

- 適用情況：node 左邊太重，且 child 沒有偏右。
- 動作：child 升為新根，node 成為 child 的右子節點，grand_child 改掛 node 的左邊。
- 為什麼仍是 BST：大小順序為 child、grand_child、node，旋轉前後中序走訪不變。
- 成本：只改固定幾個指標並更新兩個節點高度，O(1)。

```java
TreeNode rightRotate(TreeNode node) {
    TreeNode child = node.left;
    TreeNode grandChild = child.right;
    child.right = node;
    node.left = grandChild;
    updateHeight(node);
    updateHeight(child);
    return child;
}
```

### 這東西用在哪

- 寫程式的人：資料常增刪又要保持排序、快速查找時選自我平衡的樹（Java TreeMap／TreeSet 底層是紅黑樹，同樣靠旋轉修復）。
- 產品端：即時排行榜、排序索引這類功能背後常是平衡樹；一百萬筆資料樹高不到 30 層，沒有平衡機制最壞可能走一百萬步。

### LeetCode

[#110 Balanced Binary Tree](https://leetcode.com/problems/balanced-binary-tree/)（Easy）

判斷每個節點左右子樹高度差是否都不超過 1。遞迴算高度，發現失衡就回傳 -1 往上傳。時間 O(n)，空間 O(h)。

```java
class Solution {
    public boolean isBalanced(
            TreeNode root) {
        return height(root) != -1;
    }

    private int height(TreeNode node) {
        if (node == null) return 0;
        int l = height(node.left);
        if (l == -1) return -1;
        int r = height(node.right);
        if (r == -1) return -1;
        int diff = Math.abs(l - r);
        if (diff > 1) return -1;
        return Math.max(l, r) + 1;
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| Rotation 旋轉 | 只改幾個指標調整樹形，不破壞 BST 順序 |
| Right rotation 右旋 | 處理左邊太重：左子節點升為新根，原根降為其右子節點 |
| Unbalanced node 失衡節點 | 平衡因子絕對值大於 1 的節點 |
| node / child / grand_child | 失衡節點／其左子節點／child 的右子節點 |
| In-order traversal 中序走訪 | 左、自己、右，BST 讀出來由小到大 |
| Subtree 子樹 | 某節點往下的整小棵樹 |
