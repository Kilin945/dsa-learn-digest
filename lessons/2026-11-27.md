## Heap / PriorityQueue：完全二元樹、上浮下沉與 Top-K · 第 5 步

### Comparator: Teaching the Heap What "Biggest" Means

![基於堆積尋找最大的 k 個元素](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_heap/top_k.assets/top_k_heap_step1.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

這張圖是上一課的 Top-K 流程：初始化小頂堆積、前 k 個入堆積、從第 k+1 個起若大於堆積頂就換進去、走訪完堆積內就是最大的 k 個。今天要看的是第三步的「大於」可以換成別的比法。

**堆積其實不知道誰「大」**：堆積每次比較兩個元素，都是去問比較器（Comparator）。比較器收到 a、b，回傳負數代表 a 排前面、正數代表 b 排前面、0 代表平手。所以堆積頂永遠是「依規則排第一」的元素。

**為什麼需要自訂規則**：堆積裡常放配對或物件（例如 [數字, 次數]、工單），要告訴它用哪個欄位比。想要大頂堆積就把 a、b 對調。堆積的上浮、下沉、Top-K 流程都不用改。

**Heap 主題五步回顧**：
1. 堆積是完全二元樹加父子大小規則，用陣列存。
2. 入堆積靠上浮、出堆積靠下沉，各 O(log n)。
3. Top-K 用大小為 k 的小頂堆積，O(n log k)。
4. 已有整包資料用建堆積，O(n)。
5. 比較規則可以自訂。

> ⚠ 比較器裡不要寫 a - b，數字大或有負數時會 overflow（溢位）而默默排錯，請用 Integer.compare(a, b)。

```java
// 預設：小的在頂
PriorityQueue<Integer> a =
  new PriorityQueue<>();

// 大頂堆積：a、b 對調
PriorityQueue<Integer> b =
  new PriorityQueue<>((x, y) ->
    Integer.compare(y, x));

// 存配對，依第二格（次數）比
PriorityQueue<int[]> c =
  new PriorityQueue<>((x, y) ->
    Integer.compare(x[1], y[1]));
```

一句話帶走：堆積的結構不變，「誰排第一」由比較器說了算。

### 這東西用在哪

**對寫程式的人**：任務排程、合併多條已排序串列、找中位數、熱門搜尋前 10 都會用 PriorityQueue 加自訂比較器，省掉每次重排整個 List 的 O(n log n)。但它只保證堆積頂是第一名，其餘位置未排序，需要完整排序結果時不適用。

**對產品端的人**：熱門搜尋、排行榜 Top 20、客服自動挑最緊急工單，背後多半是這個結構。只看前 k 名時，資料量成長對速度影響很小；換排序標準不會變慢。若需求變成「能跳到第 500 名」，就要重新評估。可以問工程師：「這個榜單是每次重排全部資料，還是只維護前 K 名？」

### LeetCode [#347 Top K Frequent Elements](https://leetcode.com/problems/top-k-frequent-elements/)（Medium）

**題目在說什麼**：給整數陣列 nums 和 k，回傳出現次數最多的前 k 個數字，順序不拘。

**解法步驟**：
1. 用 HashMap 數出每個數字的出現次數。
2. 準備大小固定為 k 的小頂堆積，放 [數字, 次數]。
3. 比較器依「次數」比大小。
4. 堆積超過 k 個就 poll 掉次數最少的。
5. 剩下的 k 個配對取出數字即答案。

**複雜度**：時間 O(n log k)（堆積最多 k+1 個元素，每次操作 O(log k)）；空間 O(n)（HashMap 最壞存 n 個不同數字）。

```java
import java.util.*;

class Solution {
  public int[] topKFrequent(
      int[] nums, int k) {
    // 先數每個數字出現幾次
    Map<Integer, Integer> cnt =
        new HashMap<>();
    for (int x : nums) {
      cnt.merge(x, 1, Integer::sum);
    }
    // 小頂堆積，依出現次數比大小
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a, b) ->
            Integer.compare(
                a[1], b[1]));
    for (var e : cnt.entrySet()) {
      pq.offer(new int[]{
          e.getKey(), e.getValue()});
      // 超過 k 個就踢掉次數最少的
      if (pq.size() > k) pq.poll();
    }
    int[] ans = new int[k];
    for (int i = 0; i < k; i++) {
      // 取出配對的第一格（數字）
      ans[i] = pq.poll()[0];
    }
    return ans;
  }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Comparator | 比較器 | 輸入兩個元素，回傳負數、0、正數，告訴堆積誰排前面 |
| Lambda | 匿名函式 | Java 的 (a, b) -> ... 簡短函式寫法 |
| Overflow | 整數溢位 | 結果超出 int 範圍，數字繞圈變錯且不報錯 |
| HashMap | 雜湊表 | 鍵對應值的對照表，這題用來記次數 |
| Min heap | 小頂堆積 | 堆積頂是依規則最小的元素，Top-K 的門檻 |
