## HashMap / HashSet：O(1) 查找的原理與代價 · 第 12 步（收尾總結）

### Wrap-up: What a Hash Table Buys You, and What It Costs

![雜湊表的抽象表示](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_hashing/hash_map.assets/hash_table_lookup.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

雜湊表（hash table，又稱散列表）在 key 與 value 之間建立對映，輸入一個 key 就能在 O(1) 時間內取得 value。例如有 n 個學生，輸入學號（key）就返回姓名（value）。

**一條主線：用算的取代找的**

雜湊函式把 key 算成雜湊值，再換算成桶的位置，所以不用逐一比對，步數不隨資料量增加，平均 O(1)。

**代價清單**

1. 雜湊衝突必然發生，要用鏈結法或開放定址法處理。
2. 負載因子超過 0.75 要擴容並 rehash，單次 O(n)，攤銷後每次 put 仍是 O(1)。
3. 要多佔一些空桶的空間。
4. 走訪順序不保證。
5. 自訂 key 要寫對 hashCode 與 equals，且放進去後不能改。

**決策地圖**

- 只問有沒有、去重：HashSet
- 對照、計數、分組：HashMap
- 要插入順序或存取順序（LRU）：LinkedHashMap
- 要排序或區間查詢：TreeMap（O(log n)）

注意：平均 O(1) 不是保證。hashCode 很爛會退化成 O(n)（Java 8 樹化後 O(log n)），擴容那一次是 O(n)。

```java
// 只問有沒有、去重
Set<String> seen = new HashSet<>();
// 數次數、建對照
Map<String, Integer> cnt =
    new HashMap<>();
// 要插入順序／LRU
Map<String, Integer> m =
    new LinkedHashMap<>();
// 要排序／區間
Map<String, Integer> t =
    new TreeMap<>();
```

### 這東西用在哪

**對寫程式的人**：看到迴圈裡再掃一次陣列找東西，就想先用 HashSet/HashMap，把 O(n²) 壓成 O(n)。可變物件當 key 沒寫好 hashCode/equals 會查不到；需要排序卻用 HashMap 順序會不固定。

**對產品端的人**：帳號是否已註冊、購物車合併、關鍵字計數背後多半是雜湊表。資料量大時單次查找仍很快，要留意的是記憶體線性增長與擴容時的短暫卡頓；需要排序或區間的需求不是它的強項。攻擊者刻意送大量撞同桶的 key 可拖慢查找（hash flooding），Java 8 樹化是保底之一。可問工程師：這個查找走雜湊還是掃全表？資料變十倍，時間和記憶體各變幾倍？

### 動手寫 · LeetCode

[#128 Longest Consecutive Sequence](https://leetcode.com/problems/longest-consecutive-sequence/)（Medium）

**題目在說什麼**：給一個沒排序的整數陣列，找出連續整數最長的長度，要求 O(n)。

**解法步驟**

1. 全部丟進 HashSet（去重，contains 平均 O(1)）。
2. 檢查每個 n：若 n-1 在集合裡，n 不是起點，跳過。
3. 只有起點才往後數 n+1、n+2…，得到這段長度。
4. 取最大值。

**複雜度**

- 時間 O(n)：只有起點才會進 while，每個數字整體最多被數到一次。
- 空間 O(n)：HashSet 存全部不重複數字。

```java
class Solution {
    public int longestConsecutive(
            int[] nums) {
        Set<Integer> set =
            new HashSet<>();
        for (int n : nums) {
            set.add(n);
        }
        int best = 0;
        for (int n : set) {
            // n-1 在集合裡就不是起點
            if (set.contains(n - 1)) {
                continue;
            }
            int cur = n + 1;
            int len = 1;
            while (set.contains(cur)) {
                cur++;
                len++;
            }
            best = Math.max(best, len);
        }
        return best;
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Hash table | 雜湊表 | 用雜湊函式把 key 算成陣列位置，平均 O(1) 存取 |
| Hash collision | 雜湊衝突 | 不同 key 算出同一個桶 |
| Load factor | 負載因子 | 元素數 ÷ 桶數，超過 0.75 Java 就擴容 |
| Amortized | 攤銷 | 把偶爾一次的昂貴操作平均分給大量便宜操作 |
| LinkedHashMap | 有序雜湊表 | HashMap 加雙向串列，記住插入或存取順序，可做 LRU |
| TreeMap | 樹狀映射 | 紅黑樹依 key 排序，O(log n)，支援區間查詢 |
