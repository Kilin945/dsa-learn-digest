## Stack 堆疊：後進先出、括號配對與單調堆疊 · 第 1 步

### 概念：LIFO（後進先出）
Stack（堆疊）是一種只能在同一端（堆疊頂）新增／刪除元素的線性資料結構，遵循 LIFO
（Last-In-First-Out，後進先出）。可以想像成一疊盤子：只能從最上面拿，也只能疊回
最上面。把新元素放上堆疊頂叫「入堆疊」（push），把堆疊頂元素拿走叫「出堆疊」（pop）。

### 為什麼只能動頂端
捨棄「任意存取」（不能像陣列用 index 直接拿中間或底部元素）的能力，換來 push／pop
都是穩定的 O(1)：不用搬動下面任何元素。

### Java 範例
```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);
stack.push(2);
stack.push(3);
int top = stack.pop(); // 3，最後放入的最先出來
```

### 用在哪
- 寫程式：函式呼叫堆疊（call stack）、瀏覽器上一頁、編輯器 undo、括號／HTML 標籤配對，都是需要「原路退回」的場景。
- 產品端：「上一步」「復原」這類功能背後多半是堆疊，所以復原通常只能一步步連續按，不能跳選要復原哪一步。

### LeetCode #20 Valid Parentheses（Easy）
https://leetcode.com/problems/valid-parentheses/

給一串只含 `( ) { } [ ]` 的字串，判斷括號是否配對且順序正確。左括號 push 進堆疊，
右括號 pop 並檢查是否對應；掃完後堆疊需清空才算合法。

複雜度：時間 O(n)（每個字元只 push/pop 一次）；空間 O(n)（最壞情況全部入堆疊）。

```java
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> pairs = new HashMap<>();
    pairs.put(')', '(');
    pairs.put(']', '[');
    pairs.put('}', '{');
    for (char c : s.toCharArray()) {
        if (!pairs.containsKey(c)) {
            stack.push(c);
            continue;
        }
        if (stack.isEmpty()) return false;
        char top = stack.pop();
        if (top != pairs.get(c)) return false;
    }
    return stack.isEmpty();
}
```

### 今日術語表
- **Stack 堆疊**：只能在同一端新增/刪除元素的資料結構
- **LIFO 後進先出**：Last-In-First-Out，最後放入的最先被拿出
- **Push 入堆疊**：把新元素放到堆疊頂
- **Pop 出堆疊**：把堆疊頂的元素拿走並回傳
- **Top / Peek 堆疊頂**：看目前最上面是誰，但不拿走
- **Deque 雙端佇列**：Java 官方建議拿來當堆疊用的介面，用 ArrayDeque 實作
