## Stack 堆疊：後進先出、括號配對與單調堆疊 · 第 6 步

### Stack Wrap-up: One Rule, Many Uses

![堆疊的先入後出規則](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_stack_and_queue/stack.assets/stack_operations.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

堆疊（stack）遵循先入後出：想拿底部的盤子，要先移走上面的。新增（push）與刪除（pop）都只發生在堆疊頂。

**一條主線**：永遠先處理最近的未完成事項。括號配對、逆波蘭表示法（RPN）都屬於這一類。

**三種長相**：
- 配對型：括號、RPN，先放進去等對的東西出現再結算。
- 單調型：單調堆疊，新元素進來先彈出不合格的頂端；每個元素最多進出一次，所以 O(n)。
- 多帶資訊型：輔助堆疊，每一格多記一份資訊（例如到此為止的最小值）。

**易錯**：堆疊只適合「最近的先處理」；先來先處理是佇列（queue），隨機存取是陣列。

### 這東西用在哪

- 寫程式：巢狀結構、undo、下一個更大／更小元素；呼叫堆疊太深會 StackOverflowError。
- 產品端：「復原」功能多半是堆疊，速度不受歷史長度影響，但記憶體會；所以常限制最多復原步數。

### LeetCode 155. Min Stack（Medium）

連結：[Min Stack](https://leetcode.com/problems/min-stack/)

設計堆疊，支援 push、pop、top、getMin，且全部 O(1)。

解法：兩個堆疊，data 存值，mins 存到這一格為止的最小值，push/pop 同步。時間 O(1)，空間 O(n)。

```java
class MinStack {
    // 主堆疊，存所有數字
    private Deque<Integer> data =
        new ArrayDeque<>();
    // 輔助堆疊，頂端是目前最小值
    private Deque<Integer> mins =
        new ArrayDeque<>();

    public void push(int val) {
        data.push(val);
        int m = val;
        if (!mins.isEmpty()) {
            int old = mins.peek();
            // 新值與舊最小值取小
            m = Math.min(m, old);
        }
        mins.push(m);
    }

    public void pop() {
        // 兩個堆疊同步彈出
        data.pop();
        mins.pop();
    }

    public int top() {
        return data.peek();
    }

    public int getMin() {
        return mins.peek();
    }
}
```

### 術語表

- LIFO 後進先出：最後放進去的最先被拿出來。
- Auxiliary stack 輔助堆疊：與主堆疊同步進出、多記一份資訊的堆疊。
- Queue 佇列：先進先出的排隊結構。
- Call stack 呼叫堆疊：記錄函式呼叫層級的堆疊。
