## 二元樹走訪：前序/中序/後序 DFS 與 BFS 層序 · 第 4 步

### Choosing a Traversal: BFS or DFS, and Which Order?

![二元樹的層序走訪](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree_traversal.assets/binary_tree_bfs.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

層序走訪從頂部到底部逐層走訪，每一層從左到右。它屬於廣度優先走訪（BFS），像「一圈一圈向外擴展」。BFS 藉助佇列（先進先出）實現，上一層先進隊先處理，所以一定先處理完這一層才輪到下一層。時間 O(n)；空間 O(n)，最差情況（滿二元樹）走到最底層前佇列最多有 (n+1)/2 個節點。

![二元搜尋樹的前序、中序、後序走訪](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree_traversal.assets/binary_tree_dfs.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

DFS 像是繞著整棵樹外圍走一圈，每個節點會遇到三個位置，分別對應前序、中序、後序。三種順序路線相同，差別只在什麼時候訪問當前節點。

### 怎麼選

- **BFS**：在乎層級（按層輸出、找最近的、層數）。
- **前序**：先處理自己再處理孩子（複製樹、序列化、把資訊往下傳）。
- **中序**：二元搜尋樹上由小到大（一般二元樹不保證排序）。
- **後序**：自己的答案要靠孩子的答案（高度、資料夾總大小、由下往上刪除）。

口訣：資訊往上流用後序，往下傳用前序，要分層用 BFS。

### 這東西用在哪

- 工程師：算目錄容量、留言總數、組織圖總人數是後序；組織圖按層顯示是 BFS。BFS 佇列取決於樹的寬度，DFS 堆疊取決於樹的深度。
- 產品端：一次走遍整棵樹是 O(n)，資料變 10 倍時間約 10 倍；若每個節點都再走一遍整棵樹就會變成 O(n²)，這才是會變慢的風險。

### LeetCode #104 Maximum Depth of Binary Tree（Easy）

連結：[Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

題目：回傳二元樹從根到最遠葉子的節點數，空樹為 0。

解法（後序）：
1. 空節點高度為 0（遞迴終點）。
2. 遞迴取得左子樹高度。
3. 遞迴取得右子樹高度。
4. 取較大者加 1 回傳。

複雜度：時間 O(n)，每個節點只遞迴一次；空間 O(h)，呼叫堆疊最深為樹高，最壞（歪斜樹）O(n)。

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // 空樹高度是 0，遞迴終點
        if (root == null) return 0;
        // 先問左子樹有多高
        int lh = maxDepth(root.left);
        // 再問右子樹有多高
        int rh = maxDepth(root.right);
        // 後序：孩子答案到手才算自己
        return Math.max(lh, rh) + 1;
    }
}
```

### 術語表

| 術語 | 白話定義 |
|---|---|
| BFS 廣度優先 | 一層一層向外擴展，靠佇列 |
| DFS 深度優先 | 先走到盡頭再回溯，含前／中／後序 |
| Queue 佇列 | 先進先出的排隊結構 |
| 二元搜尋樹 | 左邊都比自己小、右邊都比自己大的二元樹 |
| Height 高度 | 從根往下最遠能走幾層 |
| Base case 遞迴終點 | 遞迴直接給答案、不再往下的情況 |
