## 平衡樹 AVL：BST 為什麼會退化、旋轉怎麼救回來 · 第 1 步

### Why a BST degrades, and what "balanced" means (Balance Factor)

在完美二元樹中插入兩個節點後，樹會嚴重向左傾斜，查詢時間隨之劣化。

![AVL 樹在刪除節點後發生退化](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/avl_tree.assets/avltree_degradation_from_removing_node.png)

經過兩次刪除節點，這棵 BST 會退化為鏈結串列。

**問題：樹高決定一切**

BST 的查詢、插入、刪除都是從根往下走，步數取決於樹高。樹矮胖時約 log n 步，樹瘦長時最多 n 步。

**平衡因子：把「歪多少」變成數字**

平衡因子 = 左子樹高度 − 右子樹高度。AVL 樹要求每個節點的平衡因子都在 -1、0、1 之間。

**為什麼差 1 就夠了**

完全一樣高太嚴格，差 1 的寬鬆限制就足以讓樹高維持在 log n 等級。平衡因子絕對值大於 1 的節點叫失衡節點，AVL 在每次插入或刪除後用旋轉修復，旋轉不會破壞 BST 的左小右大。

**易錯**：平衡因子比的是高度（層數），不是節點數量。

```java
// 節點高度：空節點 -1，葉子 0
int height(TreeNode n) {
    return n == null ? -1 : n.height;
}

// 平衡因子 = 左高 - 右高
int balanceFactor(TreeNode n) {
    if (n == null) return 0;
    return height(n.left)
         - height(n.right);
}

// 失衡：絕對值大於 1
boolean isUnbalanced(TreeNode n) {
    return Math.abs(balanceFactor(n))
         > 1;
}
```

### 這東西用在哪

- 寫程式：需要持續排序又要快速查、插、刪時用自平衡樹（Java 的 TreeMap 是紅黑樹）。手刻普通 BST 遇到排序過的輸入會退化成 O(n)。
- 產品端：排行榜、範圍篩選背後常是排序樹。平衡時一萬筆約 14 步，退化時一萬步；測試時快、上線後資料變多突然變慢是典型症狀。

### 動手寫 · LeetCode

[#110 Balanced Binary Tree](https://leetcode.com/problems/balanced-binary-tree/)（Easy）

題目：判斷一棵二元樹是否每個節點的左右子樹高度差都不超過 1。

步驟：
1. 寫 height 遞迴算高度。
2. 算完左右高度後檢查差的絕對值是否大於 1。
3. 發現失衡就回傳 -1，一路往上傳。
4. 最外層只看結果是不是 -1。

複雜度：時間 O(n)，每個節點只拜訪一次；空間 O(h)，遞迴深度等於樹高。

```java
class Solution {
    public boolean isBalanced(
            TreeNode root) {
        return height(root) != -1;
    }

    // 回傳高度；失衡就回傳 -1
    private int height(TreeNode node) {
        // 空節點高度為 0
        if (node == null) return 0;

        int l = height(node.left);
        // 左邊已失衡，直接往上傳
        if (l == -1) return -1;

        int r = height(node.right);
        if (r == -1) return -1;

        // 平衡因子絕對值大於 1
        if (Math.abs(l - r) > 1) {
            return -1;
        }
        return Math.max(l, r) + 1;
    }
}
```

### 今日術語表

| 術語 | 白話定義 |
|---|---|
| BST 二元搜尋樹 | 每個節點左子樹都比它小、右子樹都比它大的二元樹 |
| Height 樹高 | 從某節點往下到最深葉子的層數 |
| Degeneration 退化 | 樹變成像鏈結串列的一條直線，操作從 O(log n) 變 O(n) |
| Balance Factor 平衡因子 | 左子樹高度減右子樹高度 |
| AVL Tree AVL 樹 | 每個節點平衡因子都在 -1 到 1 之間的自平衡 BST |
| Unbalanced node 失衡節點 | 平衡因子絕對值大於 1 的節點 |
| Rotation 旋轉 | 調整節點父子關係降低樹高，且不破壞 BST 規則 |
