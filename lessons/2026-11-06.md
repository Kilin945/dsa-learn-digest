## 二元樹走訪：前序/中序/後序 DFS 與 BFS 層序 · 第 2 步

### DFS: Preorder, Inorder, Postorder

![二元搜尋樹的前序、中序、後序走訪](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree_traversal.assets/binary_tree_dfs.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

深度優先走訪像是繞著整棵二元樹的外圍走一圈，在每個節點都會遇到三個位置，分別對應前序、中序、後序。三種走訪路線相同，差別只在何時「訪問」當前節點。

![前序走訪的遞迴過程](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree_traversal.assets/preorder_step1.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

遞迴分成「遞」（開啟新方法、訪問下一個節點）與「迴」（函式返回，代表當前節點訪問完畢）。

**概念**

- DFS：先沿一條路走到盡頭，再回溯。
- 前序：自己、左、右；中序：左、自己、右；後序：左、右、自己。
- 範例樹：根 1，1 的左孩子 2、右孩子 3，2 的左孩子 4、右孩子 5。前序 1,2,4,5,3；中序 4,2,5,1,3；後序 4,5,2,3,1。
- 時間 O(n)（每節點一次）；空間最壞 O(n)（遞迴深度等於樹高，平衡時 O(log n)）。
- 易錯：三種序都是先左後右，名字指的是「根」相對左右子樹的訪問時間。

```java
void dfs(TreeNode node) {
    // 終止條件：空節點就返回
    if (node == null) return;
    // 位置 1：前序在這裡訪問
    dfs(node.left);
    // 位置 2：中序在這裡訪問
    dfs(node.right);
    // 位置 3：後序在這裡訪問
}
```

### 這東西用在哪

- 寫程式：前序用於複製／序列化；BST 中序得到由小到大；後序用於需要先拿到孩子結果的計算（樹高、資料夾大小、刪除）。遞迴太深會 StackOverflowError，需改迭代。
- 產品端：資料夾、組織圖、留言串、多層分類多半是樹；整棵走訪時間大致與節點數成正比，資料量大時考慮分段載入或預先算好。

### LeetCode

[#94 Binary Tree Inorder Traversal](https://leetcode.com/problems/binary-tree-inorder-traversal/)（Easy）

中序（左、自己、右）收集所有節點值。dfs：null 返回；dfs(left)；加入 val；dfs(right)。時間 O(n)，空間 O(n)（最壞樹高 n）。

```java
class Solution {
    public List<Integer>
            inorderTraversal(
                TreeNode root) {
        List<Integer> res =
            new ArrayList<>();
        dfs(root, res);
        return res;
    }

    private void dfs(TreeNode node,
            List<Integer> res) {
        // 終止條件：空節點就返回
        if (node == null) return;
        // 先處理整棵左子樹
        dfs(node.left, res);
        // 中序：左邊做完才記錄自己
        res.add(node.val);
        // 最後處理整棵右子樹
        dfs(node.right, res);
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| DFS 深度優先搜尋 | 先走到盡頭再回頭的走訪 |
| Preorder 前序 | 自己、左、右 |
| Inorder 中序 | 左、自己、右 |
| Postorder 後序 | 左、右、自己 |
| Recursion 遞迴 | 函式呼叫自己處理更小的問題 |
| Base case 終止條件 | 遞迴的出口 |
| Call stack 呼叫堆疊 | 記錄函式層層呼叫的空間 |
| BST 二元搜尋樹 | 左小右大的二元樹 |
