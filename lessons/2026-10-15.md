## HashMap / HashSet：O(1) 查找的原理與代價 · 第 7 步

### Treeification：桶裡的鏈太長時

![雜湊衝突示例](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_hashing/hash_map.assets/hash_collision.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

圖中雜湊函式只看學號後兩位，所以學號 12836 和 20336 都指向同一個姓名，這就是雜湊衝突：多個輸入對應同一個輸出。輸入空間遠大於輸出空間，所以衝突理論上一定存在。

**問題：鏈太長就退化。** 鏈結法下查找成本是 O(1 + 鏈長)。hashCode 寫得差或遭惡意構造時，所有資料可能落在同一條鏈，查找退化成 O(n)。

**解法：換成紅黑樹。** Java 8 起，單一桶鏈長達 8 且桶數至少 64，就把串列轉成紅黑樹（自動保持平衡的排序樹）。每層比大小排除一半，100 萬筆約 20 步，最壞情況 O(log n)。

**何時轉、何時轉回。** 桶數不足 64 時優先擴容；樹縮到 6 個以下會轉回串列。樹化只是保底，正常情況鏈長多半是 0 到 2。

> ⚠ 最容易搞錯：樹要靠比大小，key 需實作 Comparable。若 key 沒實作 Comparable 且 hashCode 全相同，樹化救不了，查找仍要翻遍整棵樹。好的 hashCode 才是正解。

```java
class BadKey
        implements Comparable<BadKey> {
    final int id;
    BadKey(int id) { this.id = id; }

    // 故意讓所有 key 都算出同一個值
    @Override
    public int hashCode() { return 1; }

    @Override
    public boolean equals(Object o) {
        return o instanceof BadKey b
            && b.id == id;
    }

    // 有實作比大小，樹化後才有用
    @Override
    public int compareTo(BadKey o) {
        return Integer.compare(
            id, o.id);
    }
}
```

一句話：鏈長達 8（且桶數至少 64）就轉成紅黑樹，把最壞情況從 O(n) 壓到 O(log n)。

### 這東西用在哪

- 寫程式的人：自訂 key 要寫好 hashCode 並盡量實作 Comparable，把樹化當保險；hashCode 寫爛不會報錯，只會悄悄變慢。
- 產品端：用代號查資料的功能多半是雜湊表，資料從千筆長到百萬筆速度幾乎不變；使用者可控的輸入當 key 時要留意 hash flooding 攻擊，現代語言多半已有防護。可問工程師：「使用者可控的輸入拿去當 key，最壞情況會慢到什麼程度？有沒有防護？」

### LeetCode · [#49 Group Anagrams](https://leetcode.com/problems/group-anagrams/)（Medium）

**題目**：把字母組成相同、順序不同的字串歸成同一組。

**解法**：
1. 字串排序後得到 key（字母組合相同則 key 相同）。
2. value 是 List，存所有屬於該 key 的原字串。
3. 掃一輪，用 computeIfAbsent 取出或新建 List 並加入原字串。
4. 回傳 map.values()。

**複雜度**：時間 O(n · k log k)，每個字串排序一次，HashMap 存取平均 O(1)；空間 O(n · k)，所有字串都存進 map。

```java
class Solution {
    public List<List<String>>
        groupAnagrams(
            String[] strs) {
        Map<String, List<String>> map =
            new HashMap<>();
        for (String s : strs) {
            char[] cs = s.toCharArray();
            // 排序後字母組合相同就是同組
            Arrays.sort(cs);
            String key = new String(cs);
            map.computeIfAbsent(key,
                k -> new ArrayList<>())
                .add(s);
        }
        return new ArrayList<>(
            map.values());
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Treeification | 樹化 | 桶內鏈太長時把串列換成樹，Java 8 起鏈長達 8 且桶數至少 64 觸發 |
| Red-black tree | 紅黑樹 | 自動保持平衡的排序樹，查找 O(log n) |
| O(log n) | 對數時間 | 資料翻倍只多一步，100 萬筆約 20 步 |
| Comparable | 可比較 | Java 介面，實作後物件可比大小 |
| Hash flooding | 雜湊洪水攻擊 | 故意送大量撞同桶的 key 使雜湊表變慢 |
