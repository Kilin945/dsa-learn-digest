## 樹的經典題型：深度、直徑、最近共同祖先 LCA · 第 2 步

### Diameter of a Binary Tree（二元樹的直徑）

**直徑是什麼**：樹中任兩個節點之間最長路徑的「邊數」（不是節點數），這條路徑不一定經過根節點。

**關鍵觀察**：任一條路徑都有一個最高節點，經過節點 x 的最長路徑 = depth(左) + depth(右)。答案 = 所有節點這個值的最大值。

**小例子**：根 1，子節點 2、3，節點 2 的子節點 4、5。節點 2 的總和 = 1 + 1 = 2；節點 1 的總和 = 2 + 1 = 3；直徑為 3（路徑 4→2→1→3）。

**暴力解 vs 一趟解**：暴力解對每個節點各呼叫一次 depth，最糟歪斜樹為 O(n²)。改成在算 depth 的同一趟後序走訪中順手更新答案，每個節點只造訪一次，時間 O(n)，空間 O(h)。

**⚠ 最容易搞錯**：回傳給父節點的是單邊深度 `1 + max(左, 右)`；更新答案用的是兩邊相加 `左 + 右`。兩者不能混用，否則路徑會在父節點分岔成三叉。

```java
int diameter(TreeNode node) {
    if (node == null) return 0;
    // depth 是昨天寫的函式
    int through = depth(node.left)
        + depth(node.right);
    int l = diameter(node.left);
    int r = diameter(node.right);
    // 取三者最大：經過我、在左、在右
    return Math.max(through,
        Math.max(l, r));
}
```

### 這東西用在哪

- **寫程式的人**：「回傳單邊結果、全域變數收兩邊結果」是一整類樹題的共同套路（LeetCode 124 最大路徑和、110 平衡樹）。每個節點重算 depth 會變 O(n²)；歪斜樹過深時遞迴可能 StackOverflowError。
- **產品端**：組織架構、推薦關係鏈、分類目錄等「最遠兩點相隔幾層」的指標，做對是掃一遍、工作量與節點數成正比；做成暴力版是平方成長，資料量大時會從瞬間變卡住。可問工程師：「這個統計是整棵樹掃一遍，還是每個節點都重算一次？」

### 動手寫 · LeetCode

[#543 Diameter of Binary Tree](https://leetcode.com/problems/diameter-of-binary-tree/)（Easy）

**題目在說什麼**：給二元樹根節點，回傳直徑（任兩節點間最長路徑的邊數），路徑可以不經過根。

**怎麼解**：
1. 準備成員變數 best = 0。
2. depth(null) = 0。
3. 後序走訪：先算 left、right。
4. best = max(best, left + right)。
5. 回傳 1 + max(left, right)。
6. 呼叫 depth(root)，回傳 best。

**複雜度**：時間 O(n)，每個節點只造訪一次；空間 O(h)，遞迴堆疊深度等於樹高。

```java
class Solution {
    // 全域答案：最長路徑的邊數
    private int best = 0;

    public int diameterOfBinaryTree(
            TreeNode root) {
        depth(root);
        return best;
    }

    // 回傳以 node 為頂點的最大深度
    private int depth(TreeNode node) {
        if (node == null) return 0;
        int left = depth(node.left);
        int right = depth(node.right);
        // 經過 node 的最長路徑(邊數)
        best = Math.max(best,
            left + right);
        // 只回傳單邊深度給父節點
        return 1 +
            Math.max(left, right);
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Diameter | 直徑 | 任兩節點間最長路徑的邊數，不一定經過根 |
| Edge | 邊 | 連接兩節點的線；節點數 = 邊數 + 1 |
| Path | 路徑 | 沿邊從一個節點走到另一個節點的路線 |
| Leaf | 葉子節點 | 沒有子節點的末端節點 |
| Post-order | 後序走訪 | 先左、再右、最後處理自己 |
| Field | 成員變數 | 類別內所有方法共用的變數 |
| StackOverflowError | 堆疊溢位 | 遞迴太深超過上限而當掉 |
