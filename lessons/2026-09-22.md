## Linked List 基礎：節點、指標與 dummy head 技巧 · 第 1 步

### 今天學的概念

鏈結串列（Linked List）是一種線性資料結構，跟陣列不同的地方在於：陣列的元素要放在一整塊連續的記憶體空間裡，鏈結串列則是由一個個獨立的節點（node）物件組成，節點之間靠「引用」（reference，也叫指標 pointer）相連，不需要連續的記憶體空間。

每個節點裝兩件事：值（value）與指向下一個節點的引用。從頭節點（head node）開始，順著引用一步步往下走，就能走訪整個串列——但也因為只能這樣一步步走，鏈結串列沒辦法像陣列一樣直接用 index 跳到第 n 個節點，找到第 n 個節點要 O(n) 的時間。

### 程式碼：定義一個節點

```java
class ListNode {
    int val;
    ListNode next;

    ListNode(int val) {
        this.val = val;
    }
}
```

### LeetCode：[1290. Convert Binary Number in a Linked List to Integer](https://leetcode.com/problems/convert-binary-number-in-a-linked-list-to-integer/)（Easy）

```java
class Solution {
    public int getDecimalValue(
            ListNode head) {
        int result = 0;
        ListNode cur = head;
        while (cur != null) {
            // 結果乘 2，
            // 再加上這個節點的值
            result = result * 2
                    + cur.val;
            cur = cur.next;
        }
        return result;
    }
}
```

時間複雜度 O(n)：要走訪每個節點恰好一次。
空間複雜度 O(1)：只用了幾個變數，沒有額外跟輸入大小成正比的空間。

### 術語表
- Linked List / 鏈結串列：元素（節點）靠引用串起來，不用連續記憶體的線性結構。
- Node / 節點：裝著值與指向下一個節點引用的基本單位。
- Reference（Pointer） / 引用（指標）：記著下一個東西的記憶體位址的路標。
- Head node / 頭節點：串列的第一個節點，常用來代稱整個串列。
- Traverse / 走訪：從頭節點開始一路順著引用往下走的動作。
