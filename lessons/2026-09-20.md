## 字串 String · 第 2 步

### StringBuilder：可變的字串緩衝區

- String 不可變，迴圈中用 `+` 串接字串會不斷複製整段舊內容，時間複雜度 O(n²)。
- StringBuilder 內部維護一塊可動態成長的緩衝區（概念上是陣列），append() 只要空間夠就直接寫入尾端；空間不夠才「擴容」換更大陣列並搬移舊資料。
- 因為擴容不是每次都發生，攤平計算（amortized analysis）下，append() 平均是 O(1)，組出長度 n 的字串整體是 O(n)。

```java
// 錯誤：O(n²)
String result = "";
for (int i = 0; i < n; i++) {
    result = result + i;
}

// 正確：O(n)
StringBuilder sb = new StringBuilder();
for (int i = 0; i < n; i++) {
    sb.append(i);
}
String result2 = sb.toString();
```

### 練習：#38 Count and Say (Medium)

[題目連結](https://leetcode.com/problems/count-and-say/)

```java
public String countAndSay(int n) {
    String result = "1";
    for (int i = 1; i < n; i++) {
        result = next(result);
    }
    return result;
}

private String next(String s) {
    StringBuilder sb = new StringBuilder();
    int count = 1;
    int len = s.length();
    char prev = s.charAt(0);
    for (int i = 1; i < len; i++) {
        char c = s.charAt(i);
        if (c == prev) {
            count++;
        } else {
            sb.append(count);
            sb.append(prev);
            count = 1;
            prev = c;
        }
    }
    sb.append(count);
    sb.append(prev);
    return sb.toString();
}
```

複雜度：時間 O(n·L)（L 為最終字串長度，需跑 n 輪、每輪掃描並用 StringBuilder 組字串）；空間 O(L)（暫存正在建構的字串）。

### 術語表

- **StringBuilder**：可變字串建構器，內部用動態陣列當緩衝區，append 後用 toString() 產生 String。
- **mutable（可變）**：建立後內容可直接修改，不必產生新物件。
- **amortized（平攤分析）**：把偶爾發生的昂貴操作（如擴容）平均分攤到每次操作，得出平均成本。
- **擴容（resize）**：內部陣列裝滿時換更大陣列並搬移舊資料。
- **buffer（緩衝區）**：暫存、逐步被填滿或讀取的一塊記憶體。
