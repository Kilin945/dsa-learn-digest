## Binary Search Tree：中序走訪的有序性與插入刪除 · 第 2 步

### BST Insert & Delete：改動樹的時候，要保住「左 < 根 < 右」

![在二元搜尋樹中插入節點](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_search_tree.assets/bst_insert.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**插入**：從根節點出發，依大小往左或往右走，直到越過葉節點（走到 None）；用 pre 記住上一輪節點，最後把新節點掛在 pre 底下。BST 不允許重複值，已存在就不插入。新節點一定長在最底端，既有節點不用搬動。

**刪除**：先找到目標節點，再依度（子節點數）分三種：

- 度為 0（葉節點）：直接刪除。
- 度為 1：用它的子節點取代它。
- 度為 2：用右子樹最小節點（中序後繼）或左子樹最大節點當替身。

![在二元搜尋樹中刪除節點（度為 2）](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_search_tree.assets/bst_remove_case3_step1.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

度為 2 的流程：1. 找到中序後繼 tmp；2. 用 tmp 的值覆蓋待刪節點的值，再遞迴刪除 tmp。tmp 是右子樹最小節點，不可能有左小孩，所以那次刪除一定是度 0 或度 1。

**複雜度**：插入、刪除、查找都是 O(h)，h 為樹高；平衡時 O(log n)，退化成鏈結串列時 O(n)。

```java
void insert(int num) {
    // 空樹的情況這裡先省略
    TreeNode pre = null;
    TreeNode cur = root;
    while (cur != null) {
        // 已存在就不插入
        if (cur.val == num) return;
        // 記住上一個節點
        pre = cur;
        if (cur.val < num)
            cur = cur.right;
        else
            cur = cur.left;
    }
    TreeNode n = new TreeNode(num);
    // 掛在 pre 的左邊或右邊
    if (pre.val < num) pre.right = n;
    else pre.left = n;
}
```

### 這東西用在哪

- 寫程式：要邊增減邊保持有序、又要查 floor／ceiling 時選 BST 家族；Java 的 TreeMap／TreeSet 底層是自平衡的紅黑樹。自己手寫不平衡的 BST，依序插入會退化成 O(n)。
- 產品端：即時排行榜、競標清單這類增減頻繁又要保持排序的功能，背後常是樹。平衡的樹一萬筆約 14 層、一百萬筆約 20 層；沒平衡又依序灌資料就會歪成一條線而變慢。可問工程師：「資料依序灌進來會不會歪？有沒有自動平衡？」

### LeetCode

[#450 Delete Node in a BST](https://leetcode.com/problems/delete-node-in-a-bst/)（Medium）

題意：給 BST 的根節點與 key，刪除值為 key 的節點，回傳刪完後的根，樹仍須是合法 BST。

解法步驟：

1. key 較小往左、較大往右，遞迴結果接回 left／right。
2. 找到且左子樹為空：回傳右子樹。
3. 找到且右子樹為空：回傳左子樹。
4. 左右都有：往右子樹一路向左找最小節點 tmp。
5. 把 tmp 的值抄到目前節點，再到右子樹遞迴刪除 tmp 的值。
6. 回傳目前節點。

複雜度：時間 O(h)，找節點與找替身各走一條由上往下的路；空間 O(h)，遞迴堆疊深度最多等於樹高。

```java
public TreeNode deleteNode(
        TreeNode root, int key) {
    if (root == null) return null;
    if (key < root.val) {
        root.left =
            deleteNode(root.left, key);
    } else if (key > root.val) {
        root.right =
            deleteNode(root.right, key);
    } else {
        // 度為 0 或 1：用子節點頂替
        if (root.left == null)
            return root.right;
        if (root.right == null)
            return root.left;
        // 度為 2：找右子樹最小節點
        TreeNode tmp = root.right;
        while (tmp.left != null) {
            tmp = tmp.left;
        }
        // 抄值，再刪掉替身
        root.val = tmp.val;
        root.right = deleteNode(
            root.right, tmp.val);
    }
    return root;
}
```

### 術語表

| 術語 | 中文 | 定義 |
| --- | --- | --- |
| Insert | 插入 | 沿大小關係往下走到空位，把新節點掛上去 |
| Delete | 刪除 | 先找到節點再拿掉，並保持 BST 規矩 |
| Degree | 度 | 一個節點有幾個子節點（0、1 或 2） |
| Leaf | 葉節點 | 沒有子節點的節點，度為 0 |
| Inorder successor | 中序後繼節點 | 中序序列中排在某節點後面的那個；度為 2 時即右子樹最小節點 |
| Recursion | 遞迴 | 函式呼叫自己，把問題縮小 |
| Height | 樹高 | 根到最深葉節點的層數，決定 BST 操作成本 |
