## Heap / PriorityQueue：完全二元樹、上浮下沉與 Top-K · 第 4 步

### Build Heap: heapify in O(n)

![完美二元樹的各層節點數量](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_heap/build_heap.assets/heapify_operations_count.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**圖在講什麼**：完美二元樹（每層都塞滿）有 n 個節點時，葉節點有 (n+1)/2 個，需要下沉的節點約 n/2 個。粗估「n/2 個節點 × 最多 log n 步」是 O(n log n)，但不準確，因為底層節點數量遠多於頂層。底層人多但幾乎不用動，頂層人少才要走長路，總和是 O(n)。

**兩種建堆積方法**：
- 逐筆 offer（每次上浮）：n × O(log n) = O(n log n)。
- 由後往前下沉：從最後一個非葉節點 n/2 - 1 走到根，總共 O(n)。

**為什麼從 n/2 - 1 開始**：葉節點本身就是合法的小堆積，不用處理。輪到某個節點時，它底下兩棵子樹已經整理好。

**為什麼是 O(n)**：最底層非葉節點最多下沉 1 步，往上一層 2 步，只有根要走完 log n 步；底層節點數約是上一層的兩倍，所以總工作量是線性。

> ⚠ 最容易搞錯：一定要由後往前做。下沉的前提是子樹已經是合法堆積，由前往後做結果不保證正確。

```java
// 建大頂堆積：由後往前逐一下沉
void buildHeap(int[] a) {
    int n = a.length;
    // 最後一個非葉節點是 n/2 - 1
    for (int i = n / 2 - 1; i >= 0; i--)
        siftDown(a, n, i);
}

void siftDown(int[] a, int n, int i) {
    while (true) {
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int m = i;
        // 找出自己、左、右中最大的
        if (l < n && a[l] > a[m])
            m = l;
        if (r < n && a[r] > a[m])
            m = r;
        // 已經最大，停止下沉
        if (m == i) break;
        int t = a[i];
        a[i] = a[m];
        a[m] = t;
        i = m;
    }
}
```

**一句話**：一次拿到整包資料，就從最後一個非葉節點往前逐一下沉，總成本 O(n)。

### 這東西用在哪

**對寫程式的人**：資料一次到齊時用 new PriorityQueue<>(collection)（內部建堆積，O(n)）；資料陸續到達才逐筆 offer。addAll 是逐筆加入，不是建堆積。建構子只吃自然排序，要大頂堆積可存負值。

**對產品端的人**：一次上傳十萬筆工單、每天凌晨整批重排優先級，這類「整批進來、要馬上找出最優先者」的功能背後常用建堆積。整批重建的時間大致與資料量成正比；逐筆插入略多於線性。一萬筆差距不明顯，千萬筆的批次作業才會浮現。可以問工程師：「這批資料是一次整批進來，還是一筆一筆進來？」

### 動手寫 · LeetCode

[#2208 Minimum Operations to Halve Array Sum](https://leetcode.com/problems/minimum-operations-to-halve-array-sum/)（Medium）

**題目在說什麼**：給正整數陣列，每次可把任一數字換成自己的一半（可以是小數），問最少操作幾次，才能讓總和至少減少一半。

**怎麼用今天學的東西解**：
1. 貪心：每次砍當前最大的數。
2. 先算總和 sum，目標是累積減少量 cut 達到 sum / 2。
3. 數字存成負數放進 List，用 new PriorityQueue<>(list) 一次建堆積（O(n)），小頂堆積存負值等於大頂堆積。
4. 迴圈：poll 最大值（取負還原）、減半、cut 加上這一半、把剩下的一半取負 offer 回去，次數加一。
5. cut 達到目標就回傳次數。

**複雜度**：
- 時間 O(n + k log n)，k 為操作次數：建堆積 O(n)，每次操作一次 poll、一次 offer，各 O(log n)。
- 空間 O(n)：List 與堆積各裝 n 個數字。

**一句話**：一次建堆積，之後反覆取最大、減半、放回。

```java
public int halveArray(int[] nums) {
    List<Double> list = new ArrayList<>();
    double sum = 0;
    for (int x : nums) {
        sum += x;
        // 存負值，小頂堆積變大頂堆積
        list.add(-(double) x);
    }
    // 建構子：一次建堆積，O(n)
    PriorityQueue<Double> pq =
        new PriorityQueue<>(list);
    double target = sum / 2;
    double cut = 0;
    int ops = 0;
    while (cut < target) {
        // 取出最大值，還原成正數
        double top = -pq.poll();
        double half = top / 2;
        cut += half;
        // 剩下的一半放回，一樣存負值
        pq.offer(-half);
        ops++;
    }
    return ops;
}
```
