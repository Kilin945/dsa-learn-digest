## Big-O 複雜度：怎麼估一段程式的快慢 · 第 2 步

### 概念：Nested Loops → O(n²) Quadratic Time

- 昨天學了 O(1) 和 O(n)，今天學「迴圈裡面還有迴圈」會發生什麼事。
- 比喻：n 人班級「每個人都跟每個人握手」，握手總次數約 n×n；n 從 10 變 20，握手次數變 4 倍，不是 2 倍——這就是「平方成長」。
- 在程式裡最常見的樣子是「巢狀迴圈（nested loop）」：外層跑 n 次，內層每次又跑約 n 次，總共 n×n = n² 次操作，記作 O(n²)。

### 程式碼：Two Sum 暴力解

```java
// 暴力解：從 nums 裡找兩個數字加起來等於 target
public int[] twoSumBruteForce(int[] nums, int target) {
    int n = nums.length;
    for (int i = 0; i < n; i++) {          // 外層跑 n 次
        for (int j = i + 1; j < n; j++) {  // 內層又跑約 n 次
            if (nums[i] + nums[j] == target) {
                return new int[]{i, j};
            }
        }
    }
    return new int[]{-1, -1};
}
// 外層 n 次 × 內層最多 n 次 = O(n²)
// 明天：用 HashMap 把這題從 O(n²) 優化成 O(n)
```

### 術語表

| 術語 | 定義 |
|---|---|
| Nested Loop（巢狀迴圈） | 一個迴圈裡面又包了另一個迴圈，內層每次都要跑完一整輪 |
| O(n²)（平方時間） | 操作次數約等於 n 的平方，n 變 2 倍，操作次數變 4 倍 |
| Brute Force（暴力解法） | 不特別優化、把所有可能情況都試過一遍的最直觀解法 |
