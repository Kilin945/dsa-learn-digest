## HashMap / HashSet：O(1) 查找的原理與代價 · 第 4 步

### hashCode() and equals(): the contract behind every key

![雜湊函式工作原理](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_hashing/hash_map.assets/hash_function.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

圖中講的是 key 變成桶位置的兩步：先用 hash() 算出雜湊值，再對桶數量 capacity 取模得到 index。原文以 capacity = 100、hash(key) = key 為例，雜湊函式就是 key % 100。Java 裡第一步對應 hashCode()，進桶之後的比對對應 equals()。

**Java 怎麼決定兩個 key 是同一個**

hashCode() 回傳一個 int，用來決定桶；equals() 判斷兩個物件算不算同一個。String、Integer 等內建型別已覆寫好。自訂類別若沒覆寫，預設比的是是不是同一個記憶體物件，不是內容。

**合約**

只要 a.equals(b) 為 true，a.hashCode() 就必須等於 b.hashCode()。反過來不要求：hashCode 相同是雜湊衝突，由 equals 在桶內分辨。

**只覆寫一個會怎樣**

只覆寫 equals：相同內容算出不同雜湊值，落在不同桶，get 得到 null。只覆寫 hashCode：進對桶，但 equals 說不同，也找不到。兩個都要寫，且用同一組欄位。

**⚠ 最容易搞錯**

key 放進 HashMap 後不要改影響 hashCode 的欄位，否則資料留在舊桶，找不到也刪不掉。key 最好不可變。

```java
class Point {
    final int x, y;
    Point(int x, int y) {
        this.x = x;
        this.y = y;
    }
    // 內容一樣就算相等
    @Override
    public boolean equals(Object o) {
        if (!(o instanceof Point))
            return false;
        Point p = (Point) o;
        return x == p.x && y == p.y;
    }
    // 用同一組欄位算雜湊值
    @Override
    public int hashCode() {
        return Objects.hash(x, y);
    }
}

Map<Point, Integer> m = new HashMap<>();
m.put(new Point(1, 2), 1);
// 沒覆寫上面兩個：null
// 有覆寫：1
m.get(new Point(1, 2));
```

### 這東西用在哪

- 寫程式：自訂類別當 key（座標、複合鍵）就要處理這兩個方法，可用 record 或 IDE 產生；用錯不報錯，只是查不到或悄悄重複。
- 產品端：「同一筆」的定義沒寫清楚會出現重複或刪不掉的資料；判斷用的欄位太集中，大量資料會擠進少數桶而變慢。可以問工程師：「同一筆是用哪幾個欄位判斷的？這些欄位會被修改嗎？」

### LeetCode · [#49 Group Anagrams](https://leetcode.com/problems/group-anagrams/)（Medium）

把字母相同、排列不同的單字分成一組。

1. 單字字母排序後當 key（eat、tea、ate 都變 aet）。
2. 排序後是不同的 String 物件但內容相同，String 的 equals 與 hashCode 讓它們進同一桶、被視為同組。
3. value 用 List，computeIfAbsent 沒有就建。
4. 回傳 map 所有 value。

時間 O(n · k log k)：n 個單字各排序 k log k，雜湊表存取平均 O(1)。空間 O(n · k)：所有單字都存在分組裡。

```java
class Solution {
    public List<List<String>>
        groupAnagrams(String[] a) {
        Map<String, List<String>> map =
            new HashMap<>();
        for (String s : a) {
            char[] c = s.toCharArray();
            // 排序後內容相同就是同組
            Arrays.sort(c);
            String key = new String(c);
            // 沒有這組就先建空串列
            map.computeIfAbsent(key,
                k -> new ArrayList<>())
               .add(s);
        }
        return new ArrayList<>(
            map.values());
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| hashCode() | 雜湊碼 | 物件回傳整數的方法，決定放哪個桶 |
| equals() | 相等判斷 | 判斷兩物件算不算同一個，預設比記憶體物件 |
| contract | 合約 | equals 相等則 hashCode 必須相等 |
| immutable | 不可變 | 建立後欄位不能改，適合當 key |
| record | 紀錄類別 | 自動產生 equals、hashCode 的簡短類別寫法 |
