## Binary Tree 基礎：節點、深度與陣列表示法 · 第 1 步

### Binary Tree Node & Terminology

![二元樹的常用術語](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree.assets/binary_tree_terminology.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**什麼是二元樹**：二元樹（binary tree）是非線性資料結構，代表祖先與後代的派生關係。基本單位是節點（node），每個節點包含值、左子節點引用、右子節點引用。

**跟鏈結串列的關係**：鏈結串列每個節點只有一個出口，二元樹有左、右兩個出口。新增與刪除節點都是改指標，刪除節點通常連同其子孫一起被切掉。

**子樹**：某節點的左子節點連同其下所有節點形成左子樹，右邊同理。任何節點都能當成新的根，這是遞迴在樹上好用的原因。

**常用術語**

- 根節點（root）：最頂層、沒有父節點。
- 葉節點（leaf）：沒有子節點。
- 邊（edge）：連接兩節點的線段，即引用（指標）。
- 層（level）：從頂到底遞增，根為第 1 層。
- 度（degree）：子節點數量，二元樹為 0、1、2。
- 深度（depth）：根到該節點經過的邊數。
- 高度（height）：該節點到最遠葉節點經過的邊數。

注意：層從 1 起算，根的深度是 0，兩者差 1；LeetCode 的最大深度則是數節點個數。

```java
public class TreeNode {
    // 節點存的值
    int val;
    // 左子節點的引用，沒有就是 null
    TreeNode left;
    // 右子節點的引用，沒有就是 null
    TreeNode right;
    TreeNode(int val) {
        this.val = val;
    }
}
```

### 這東西用在哪

- 寫程式：檔案系統、DOM、JSON、語法樹都是樹；TreeMap 底層是紅黑樹；HashMap 樹化也是用樹取代過長的鏈。樹長歪會退化成鏈結串列，操作變 O(n)。
- 產品端：分類目錄、組織圖、多層選單背後多半是樹；均衡的樹百萬筆資料約二十層，風險在樹有沒有長歪。

### LeetCode

[#104 Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/)（Easy）

求根到最遠葉節點路徑上的節點個數。最大深度 = max(左子樹深度, 右子樹深度) + 1，空節點為 0。時間 O(n)（每個節點拜訪一次），空間 O(h)（遞迴堆疊深度等於樹高）。

```java
class Solution {
    public int maxDepth(TreeNode root) {
        // 空樹：深度為 0
        if (root == null) {
            return 0;
        }
        int l = maxDepth(root.left);
        int r = maxDepth(root.right);
        // 取較深的一邊，再加上自己這一層
        return Math.max(l, r) + 1;
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
| --- | --- | --- |
| Binary tree | 二元樹 | 每個節點最多有左、右兩個子節點 |
| Node | 節點 | 內含值與左右子節點引用 |
| Root / Leaf | 根／葉 | 根無父節點；葉無子節點 |
| Edge | 邊 | 節點之間的引用（指標） |
| Level | 層 | 從頂到底遞增，根為 1 |
| Degree | 度 | 子節點數量，0、1、2 |
| Depth | 深度 | 根到該節點的邊數 |
| Height | 高度 | 該節點到最遠葉節點的邊數 |
| Subtree | 子樹 | 某節點的左（右）子節點及其下所有節點 |
