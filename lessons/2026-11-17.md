## 平衡樹 AVL · 第 6 步：AVL 刪除（Deletion）

### 概念

![AVL 樹在刪除節點後發生退化](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/avl_tree.assets/avltree_degradation_from_removing_node.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

原文指出，BST 經過多次插入和刪除後可能退化成鏈結串列，經過兩次刪除節點就可能發生。退化後查詢從 O(log n) 劣化為 O(n)，所以刪除時也必須做平衡檢查。

**先把節點拿掉：跟普通 BST 一樣。** 葉節點直接拿掉；只有一個子節點就讓子節點頂上；有兩個子節點就找後繼節點（右子樹最小的節點），抄值過來再刪掉後繼節點。

**回程：每層更新高度再 rebalance。** 與插入相同，遞迴回程每層先 updateHeight 再 rebalance。差別：插入修一次就全樹恢復平衡，刪除可能修好一層後子樹變矮 1，讓上一層又失衡，要一路檢查到根。

**複雜度 O(log n)。** 路徑長度是樹高 O(log n)，每層最多一次 O(1) 的旋轉。

**⚠ 最容易搞錯：** 刪除時 child 的平衡因子可能是 0。node 左重時，child 平衡因子 ≥ 0 用單純右旋，只有 child < 0 才用 LR。

```java
TreeNode remove(TreeNode node, int v) {
    if (node == null) return null;
    if (v < node.val)
        node.left =
            remove(node.left, v);
    else if (v > node.val)
        node.right =
            remove(node.right, v);
    else if (node.left == null
            || node.right == null) {
        // 0或1個子節點：直接頂上
        TreeNode child = node.left;
        if (child == null)
            child = node.right;
        return child;
    } else {
        // 2個子節點：找後繼節點
        TreeNode next = node.right;
        while (next.left != null)
            next = next.left;
        node.right =
            remove(node.right, next.val);
        node.val = next.val;
    }
    // 回程：更新高度再 rebalance
    updateHeight(node);
    return rebalance(node);
}
```

一句話：AVL 刪除 = 普通 BST 刪除 + 回程每層 updateHeight 再 rebalance；失衡可能連鎖到根，但總成本仍是 O(log n)。

### 這東西用在哪

**對寫程式的人：** 需要隨時保持排序、又頻繁新增刪除時選自平衡樹；實務直接用 TreeMap / TreeSet（紅黑樹）。手寫常見錯誤是刪除後只 rebalance 一次，或忘了回程更新高度，樹會悄悄歪掉。

**對產品端的人：** 即時排行榜、可取消的預約排程、資料庫索引背後多半是自平衡樹，資料量放大一千倍，每次操作只多十幾步。若用不會自我平衡的樹，症狀是剛上線很快、刪改多次後越來越慢。可問工程師：「大量新增刪除後查詢會不會慢慢變差？有沒有自動平衡機制？」

### LeetCode · [#450 Delete Node in a BST](https://leetcode.com/problems/delete-node-in-a-bst/)（Medium）

**題目在說什麼：** 給一棵 BST 與 key，刪掉值為 key 的節點，刪完仍是合法 BST，回傳新根。

**解題步驟：**
1. key 較小往左刪，較大往右刪，並把回傳的子樹接回去。
2. 找到後，左子節點空就回傳右子節點；右子節點空就回傳左子節點。
3. 兩個子節點都在：找右子樹最左節點（後繼節點）抄值。
4. 到右子樹刪掉後繼節點。

**複雜度：** 時間 O(h)，只沿一條路徑往下走；空間 O(h)，遞迴堆疊最深為樹高。

```java
class Solution {
    public TreeNode deleteNode(
            TreeNode root, int key) {
        if (root == null) return null;
        if (key < root.val) {
            root.left = deleteNode(
                root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(
                root.right, key);
        } else {
            // 沒有左子節點：右邊頂上
            if (root.left == null)
                return root.right;
            // 沒有右子節點：左邊頂上
            if (root.right == null)
                return root.left;
            // 兩個子節點：找後繼節點
            TreeNode next = root.right;
            while (next.left != null)
                next = next.left;
            // 抄值，再刪掉後繼節點
            root.val = next.val;
            root.right = deleteNode(
                root.right, next.val);
        }
        return root;
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Deletion | 刪除 | 把指定值的節點拿掉，仍維持 BST 順序 |
| Successor | 後繼節點 | 右子樹最小的節點，中序走訪的下一個 |
| Backtrack | 遞迴回程 | 遞迴往下做完後逐層返回的階段，此時更新高度與 rebalance |
| Cascading imbalance | 連鎖失衡 | 修好一個失衡節點後上一層又失衡，刪除可能發生、插入不會 |
| Self-balancing tree | 自平衡樹 | 每次增刪後自動調整、讓樹高維持 O(log n) 的樹 |
