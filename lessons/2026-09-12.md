## 迭代與遞迴：兩種重複的形式、呼叫堆疊與尾遞迴 · 第 1 步

### 今日概念：Iteration（迭代）

迭代是一種重複執行某個任務的控制結構：在滿足條件時反覆執行同一段程式碼，直到條件不再成立為止。for 迴圈是最常見的形式，特別適合「執行前就知道要重複幾次或重複到什麼條件」的情況。

![求和函式的流程框圖](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_computational_complexity/iteration_and_recursion.assets/iteration.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

範例：計算 1 加到 n 的總和。

```java
int sum(int n) {
    int res = 0;
    // 從 1 累加到 n
    for (int i = 1; i <= n; i++) {
        res += i;
    }
    return res;
}
```

⚠ 最容易搞錯：迭代不等於「一定要用 for 迴圈」，while 迴圈一樣是迭代，關鍵在於「有沒有在條件成立時反覆執行、條件不成立才停」。

### 這東西用在哪

- 對工程師：重複次數或結束條件在執行前就能確定時，優先用迭代而非遞迴——不會像遞迴一樣每次呼叫都多開一份堆疊空間，更省記憶體、更快。
- 對產品端：批次處理固定筆數資料（例如批次核對訂單）背後多半是單層迴圈，速度跟筆數等比例成長，不會忽然變得不成比例地慢；跟之後要教的巢狀迴圈不同。

### LeetCode 練習

[#1480 Running Sum of 1d Array](https://leetcode.com/problems/running-sum-of-1d-array/)（Easy）

把陣列每個位置換成從頭累加到該位置的總和。

```java
public int[] runningSum(int[] nums) {
    // 把前一項的和累加進來
    for (int i = 1;
            i < nums.length; i++) {
        nums[i] += nums[i - 1];
    }
    return nums;
}
```

時間 O(n)：只跑一次迴圈，沒有巢狀掃描。
空間 O(1)：直接寫回原陣列，沒有另外開陣列。

### 今日術語表

- **Iteration 迭代**：讓程式在條件成立時反覆執行同一段程式碼的控制方式。
- **for loop for 迴圈**：一開始就講好重複幾次或重複到什麼條件的迴圈寫法。
- **loop variable 迴圈變數**：記錄目前跑到第幾輪、每輪都會被更新的變數。
- **loop body 迴圈本體**：每一輪重複時真正被執行的那段程式碼。
