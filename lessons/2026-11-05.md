## 二元樹走訪：前序/中序/後序 DFS 與 BFS 層序 · 第 1 步

### Tree Traversal & Level-order (BFS)

![二元樹的層序走訪](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree_traversal.assets/binary_tree_bfs.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

層序走訪（level-order traversal）從頂部到底部逐層走訪，每一層內由左到右。它屬於廣度優先走訪（BFS），像「一圈一圈向外擴展」。

**什麼是走訪**：走訪（traversal）就是訂一套規則，讓樹上每個節點恰好被看一次。

**兩大家族**：層序屬於 BFS；前序、中序、後序屬於 DFS（先走到盡頭再回頭）。差別在於「下一個看誰」的規則。今天只學 BFS。

**用佇列實現**：佇列先進先出。先把根節點排進去，之後重複「叫出最前面的節點、看它、把左右孩子排到隊尾」，上一層的孩子自然排在後面，因此會一層一層出來。

注意：BFS 用佇列（先進先出），換成堆疊（後進先出）就會變成往深處鑽的 DFS。

```java
void bfs(TreeNode root) {
    Queue<TreeNode> q =
        new LinkedList<>();
    // 根節點先排進隊伍
    q.offer(root);
    while (!q.isEmpty()) {
        // 叫出隊伍最前面的人
        TreeNode n = q.poll();
        System.out.println(n.val);
        // 左右孩子排到隊尾
        if (n.left != null)
            q.offer(n.left);
        if (n.right != null)
            q.offer(n.right);
    }
}
```

複雜度：時間 O(n)，每個節點進出佇列各一次；空間 O(n)，最壞情況（滿二元樹）佇列同時約有 (n+1)/2 個節點。

### 這東西用在哪

- 寫程式：組織圖逐層列出、資料夾只展開前幾層、留言串依深度分層、找最近目標。用 BFS 不用自己記層數，隊伍順序已經記住了。
- 產品端：「點開一層再載入下一層」背後多半是樹。走訪時間與節點數成正比，一萬筆約是一百筆的一百倍；一次全展開在資料大時會變慢，按層載入才撐得住。

### 動手寫 · LeetCode

[#102 Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/)（Medium）

題目：回傳一個清單的清單，第 i 個清單是第 i 層由左到右的節點值。

解法步驟：

1. 根為空就回傳空清單。
2. 根放進佇列。
3. 每輪先記下 size（這一層的節點數）。
4. 只叫出 size 個節點，收進小清單，並把左右孩子排到隊尾。
5. 小清單放進結果，直到佇列空。

複雜度：時間 O(n)（每個節點處理一次）；空間 O(n)（佇列最寬一層約 (n+1)/2，加上結果清單）。

```java
public List<List<Integer>> levelOrder(
        TreeNode root) {
    List<List<Integer>> res =
        new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q =
        new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        // 目前佇列大小 = 這一層節點數
        int size = q.size();
        List<Integer> level =
            new ArrayList<>();
        for (int k = 0; k < size; k++) {
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null)
                q.offer(node.left);
            if (node.right != null)
                q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Traversal | 走訪 | 依規則把每個節點恰好看一次 |
| Node | 節點 | 樹裡存資料的一格，可指向左右孩子 |
| Root | 根節點 | 最頂端的節點，整棵樹的入口 |
| BFS | 廣度優先 | 先看離起點近的，一圈一圈向外 |
| DFS | 深度優先 | 先走到盡頭再回頭，前/中/後序屬於它 |
| Level-order | 層序走訪 | 由上到下逐層、每層由左到右，即 BFS |
| Queue / FIFO | 佇列／先進先出 | 像排隊，先進的先出 |
