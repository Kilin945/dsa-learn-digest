## 鏈結串列的指標技巧：快慢指標找中點與判環、反轉串列 · 第 1 步

### 概念：Fast & Slow Pointers（快慢指標）

兩根指標同時從 head 出發，slow 一次走一步、fast 一次走兩步。當 fast 走到串列尾端時，slow 剛好停在中點——不需要先算出串列總長度，只用速度差就能一次遍歷找到中點。

這是為了解決鏈結串列（不像陣列有索引）沒辦法直接跳到中間位置的問題：不用這招的話，得先走一遍算長度、再走一遍走到中點，等於掃兩遍；快慢指標把它合併成一遍。

⚠️ 邊界情況：長度是偶數時有兩個候選中點。迴圈條件 `fast != null && fast.next != null` 會讓 slow 停在靠後面那一個；若想停在前面那一個，條件要換成 `fast.next != null && fast.next.next != null`。

```java
// fast 一次走兩步，slow 一次走一步
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
  slow = slow.next;
  fast = fast.next.next;
}
// 迴圈結束時 slow 指向中點
```

### 用在哪

- 工程師：合併排序鏈結串列（merge sort）需要先找中點切成兩半；回文鏈結串列檢查（palindrome）需要找中點再反轉後半段比較。只走一遍，省掉先算長度的額外遍歷；用錯迴圈條件會導致偶數長度時切錯邊界。
- 產品端：若某個排序/比對功能背後用了快慢指標，代表工程師選了「資料變多、時間等比例增加（O(n)）」的省時寫法，資料從百筆長到萬筆不會突然暴增變慢。

### 練習：LeetCode #876 Middle of the Linked List（Easy）

[https://leetcode.com/problems/middle-of-the-linked-list/](https://leetcode.com/problems/middle-of-the-linked-list/)

給定 head，回傳串列中點；偶數長度回傳靠後面那一個。

複雜度：時間 O(n)（fast 最多走完整條串列一次），空間 O(1)（只用兩個指標變數）。

```java
class Solution {
  public ListNode middleNode(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {
      slow = slow.next;
      fast = fast.next.next;
    }
    return slow;
  }
}
```

### 今日術語表

| 術語 | 定義 |
|---|---|
| Fast & Slow Pointers 快慢指標 | 兩根指標同時出發、速度不同，利用速度差找出串列中的特定位置 |
| Middle Node 中點 | 串列正中間的節點；偶數長度時有兩個候選 |
| Floyd's Tortoise and Hare 龜兔賽跑演算法 | 快慢指標的正式名稱，之後判環也會用同一招 |
| Single Pass 一次遍歷 | 只掃過資料一次就得到答案，不需要掃兩遍 |
