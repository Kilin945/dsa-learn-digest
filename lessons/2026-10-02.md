## Stack 堆疊：後進先出、括號配對與單調堆疊 · 第 5 步

### Evaluating Reverse Polish Notation with a Stack

![堆疊的先入後出規則](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_stack_and_queue/stack.assets/stack_operations.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

圖的重點：堆疊像一疊盤子，只能碰到最上面的堆疊頂。讀到數字就入堆疊（push），讀到運算子就連續出堆疊（pop）兩次，算完再把結果 push 回去。

**這種寫法是什麼**

逆波蘭表示法（Reverse Polish Notation，RPN）把運算子放在兩個運算元後面，`(2 + 1) * 3` 寫成 `2 1 + 3 *`，不需要括號。

**堆疊怎麼算**

從左到右讀：運算元就 push；運算子就 pop 兩次、計算、再把結果 push。讀完後堆疊只剩一個數字，就是答案。

```
讀 2 → push → [2]
讀 1 → push → [2, 1]
讀 + → pop 1、pop 2
      算 2+1=3 → push → [3]
讀 3 → push → [3, 3]
讀 * → pop 3、pop 3
      算 3*3=9 → push → [9]
答案：9
```

**為什麼適合堆疊**

運算子用的永遠是最近出現的兩個數字，符合後進先出；算完的結果又成為最新的一個。

> ⚠ 最容易搞錯：先 pop 的是右運算元，後 pop 的是左運算元。減法與除法寫反會算錯（`6 2 /` 要是 6÷2）。

### 這東西用在哪

- 寫程式的人：處理使用者自訂公式、計價規則、條件組合時，先轉 RPN 再用堆疊求值，省去自己處理括號與優先順序；JVM 執行 bytecode 也用運算元堆疊。pop 前要檢查堆疊不為空。
- 產品端：自訂公式欄位背後多半是這種做法，一條公式的計算時間與公式長度成正比；但總工作量是「公式長度 × 套用的資料筆數」，要一起評估。

### 動手寫 · LeetCode

[#150 Evaluate Reverse Polish Notation](https://leetcode.com/problems/evaluate-reverse-polish-notation/)（Medium）

題目：給一個 RPN 字串陣列（整數與 + - * /），算出結果；除法往 0 捨去。

解法步驟：

1. 準備整數堆疊。
2. 讀到數字（含負數）就 push。
3. 讀到運算子就 pop 兩次，先 pop 的是右運算元 b，再 pop 左運算元 a。
4. 計算 a 運算子 b，push 回去。
5. 讀完後 pop 最後一個數字回傳。

複雜度：時間 O(n)，每個字串只讀一次，push／pop 都是 O(1)；空間 O(n)，最壞情況堆疊要放下約 n 個數字。

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> st =
            new ArrayDeque<>();
        for (String t : tokens) {
            if (t.length() > 1
                || Character.isDigit(
                    t.charAt(0))) {
                // 數字就 push
                st.push(
                    Integer.parseInt(t));
                continue;
            }
            // 先彈出的是右運算元 b
            int b = st.pop();
            int a = st.pop();
            if (t.equals("+")) {
                st.push(a + b);
            } else if (t.equals("-")) {
                st.push(a - b);
            } else if (t.equals("*")) {
                st.push(a * b);
            } else {
                // Java 整數除法往 0 捨去
                st.push(a / b);
            }
        }
        // 最後剩下的就是答案
        return st.pop();
    }
}
```

### 今日術語表

- **Reverse Polish Notation（逆波蘭／後綴表示法）**：運算子寫在兩個運算元後面，不需要括號。
- **Infix（中序表示法）**：平常的寫法，運算子夾在中間。
- **Operand（運算元）**：被運算的數字。
- **Operator（運算子）**：+ - * / 等運算符號。
- **Bytecode（位元組碼）**：Java 編譯後交給 JVM 執行的指令。
