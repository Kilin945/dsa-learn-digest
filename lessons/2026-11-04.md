## Binary Tree 基礎：節點、深度與陣列表示法 · 第 4 步

### Balanced vs. Degenerate Binary Tree

同樣是二元樹，長得歪不歪，決定它快還是慢。

![二元樹的最佳結構與最差結構](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree.assets/binary_tree_best_worst_cases.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

- 理想情況：每層都填滿的完美二元樹，可以充分發揮分治的優勢。
- 最差情況：所有節點偏向一側，退化成鏈結串列，各項操作變成線性操作，退化到 O(n)。

![平衡二元樹](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree.assets/balanced_binary_tree.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**平衡二元樹**：任意節點的左子樹與右子樹高度差，絕對值不超過 1。它不要求每層填滿，只要不偏向一側，高度就維持 O(log n)。

### 重點

- 操作成本看的是樹的高度，不是節點總數。高度 h 的完美二元樹有 2^(h+1) − 1 個節點，所以 n 個節點的完美樹高度約 log₂n，一百萬個節點約 20 層。
- 平衡 ≠ 完美，也不是左右節點數相同。比的是高度差，而且每個節點都要成立，不只看根。
- 與陣列表示法的連結：全部偏右的退化樹，索引依序是 0、2、6、14⋯，n 個節點需要 2^n − 1 格，幾乎全是 null；完全二元樹則一格都不浪費。

### 這東西用在哪

- 寫程式：Java 的 TreeMap、TreeSet 底層是紅黑樹；HashMap（Java 8 起）在同一格衝突太多時會把鏈結串列換成紅黑樹，避免退化成 O(n)，也緩解 hash flooding 攻擊。自己寫不平衡的搜尋樹，若依序插入已排序資料會退化成鏈結串列，遞迴深度到 n，可能 StackOverflowError。
- 產品端：即時搜尋、排行榜、時間範圍查詢背後多半是平衡的樹狀索引。資料多一萬倍，步數只從約 7 步變成約 20 步；若退化，十萬筆最差要走十萬步，對平衡的約 17 步差約六千倍。可以問工程師：這個結構會自動保持平衡嗎？資料依序灌進去會不會歪成一條線？

### LeetCode：[#110 Balanced Binary Tree](https://leetcode.com/problems/balanced-binary-tree/)（Easy）

**題目**：判斷一棵二元樹是否平衡，即每個節點的左右子樹高度差絕對值都不超過 1。

**解法步驟**

1. 寫 height(node) 回傳子樹高度（用節點數算，空樹為 0）。
2. 先遞迴算左、右子樹高度。
3. 高度差超過 1 就回傳 -1 當警報；任一邊已是 -1 就一路往上傳。
4. 否則回傳 max(左, 右) + 1。
5. 根節點回傳不是 -1 就是平衡。

**複雜度**

- 時間 O(n)：每個節點只拜訪一次，每次做 O(1) 比較。
- 空間 O(h)：遞迴深度等於樹高，平衡時 O(log n)，退化時 O(n)。

```java
class Solution {
    public boolean isBalanced(
            TreeNode root) {
        return height(root) != -1;
    }

    // 回傳子樹高度（用節點數算）
    private int height(TreeNode node) {
        if (node == null) return 0;
        int l = height(node.left);
        // 左邊已不平衡，直接往上報
        if (l == -1) return -1;
        int r = height(node.right);
        if (r == -1) return -1;
        // 差超過 1 就回傳 -1 報警
        if (Math.abs(l - r) > 1)
            return -1;
        return Math.max(l, r) + 1;
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
| --- | --- | --- |
| Balanced binary tree | 平衡二元樹 | 任意節點的左右子樹高度差絕對值不超過 1 |
| Degenerate tree | 退化的樹 | 節點全偏一側，形狀同鏈結串列，操作退化成 O(n) |
| Perfect binary tree | 完美二元樹 | 每層都填滿，高度 h 時有 2^(h+1) − 1 個節點；中文社群常稱滿二元樹 |
| Full binary tree | 完滿二元樹 | 除葉節點外，每個節點都有兩個子節點 |
| Divide and conquer | 分治 | 把大問題一分為二、各自處理 |
| Linear operation | 線性操作 | 要一個一個走過去的操作，記為 O(n) |
| Red-black tree | 紅黑樹 | 插入刪除後自動維持平衡的二元搜尋樹，TreeMap 使用 |
