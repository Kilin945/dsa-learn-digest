## Queue 佇列與 Deque:先進先出、環形佇列與雙端佇列 · 第 2 步

### Array-based Queue and the Circular Queue

![基於陣列實現佇列的入列出列操作](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_stack_and_queue/queue.assets/array_queue_step1.png)

圖:[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**陣列佇列的狀態**

- front:佇列首元素的索引。
- size:目前元素個數。
- rear = front + size:佇列尾元素之後的下一個位置。
- 有效區間為 [front, rear - 1]。
- 入列:把元素放到 rear,size + 1。
- 出列:front + 1,size - 1。
- 兩者都是 O(1)。

**問題**:front 與 rear 只往右走,陣列再空也會到盡頭放不下。

**環形佇列**:用取餘數 % cap 讓 index 繞回 0。rear = (front + size) % cap;出列 front = (front + 1) % cap。

**例子**:cap = 5、front = 3、size = 3,則 rear = (3 + 3) % 5 = 1。

**注意**:環形後空與滿時 front、rear 都可能指同一格,必須用 size 判斷:size == 0 為空,size == cap 為滿。

```java
class ArrayQueue {
    int[] nums;
    int front = 0;
    int size = 0;

    ArrayQueue(int cap) {
        nums = new int[cap];
    }

    void offer(int x) {
        int cap = nums.length;
        if (size == cap) return;
        // rear 超過尾端就用 % 繞回 0
        int rear = (front + size) % cap;
        nums[rear] = x;
        size++;
    }

    int poll() {
        if (size == 0) return -1;
        int v = nums[front];
        // front 往後一格,到底繞回 0
        front = (front + 1) % nums.length;
        size--;
        return v;
    }
}
```

### 這東西用在哪

- 寫程式:固定大小、持續進出的緩衝(ring buffer、最近 N 筆 log、限流視窗);記憶體連續、不用每次 new 節點;要先決定滿了是拒絕、蓋掉最舊還是擴容。Java 的 ArrayDeque 底層即環形陣列。
- 產品端:「最近 N 筆」「固定容量暫存區」多半是環形佇列;記憶體固定、速度不隨資料量變慢;代價是上限固定,滿了要在規格上決定拒絕或覆蓋。

### LeetCode

[#622 Design Circular Queue](https://leetcode.com/problems/design-circular-queue/)(Medium)

**題目**:實作容量 k 的環形佇列,支援 enQueue、deQueue、Front、Rear、isEmpty、isFull。

**解法步驟**

1. 陣列長度 k,front = 0,size = 0。
2. enQueue:滿則 false;放到 (front + size) % cap,size++。
3. deQueue:空則 false;front = (front + 1) % cap,size--。
4. Front 回 data[front];Rear 回 data[(front + size - 1) % cap]。
5. 用 size 判斷空與滿。

**複雜度**:時間 O(1)(每個操作只改變數並取一次餘數);空間 O(k)(只配置長度 k 的陣列)。

```java
class MyCircularQueue {
    private int[] data;
    private int cap;
    private int front = 0;
    private int size = 0;

    public MyCircularQueue(int k) {
        cap = k;
        data = new int[k];
    }

    public boolean enQueue(int value) {
        if (isFull()) return false;
        // 下一個空位 = 隊首 + 長度
        int rear = (front + size) % cap;
        data[rear] = value;
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) return false;
        front = (front + 1) % cap;
        size--;
        return true;
    }

    public int Front() {
        if (isEmpty()) return -1;
        return data[front];
    }

    public int Rear() {
        if (isEmpty()) return -1;
        // 最後一個元素在空位前一格
        int last = front + size - 1;
        return data[last % cap];
    }

    public boolean isEmpty() {
        return size == 0;
    }

    public boolean isFull() {
        return size == cap;
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| front | 佇列首索引 | 佇列第一個元素所在的格子,出列時加 1 |
| rear | 佇列尾的下一格 | 下一個新元素要放的位置,= front + size |
| size | 目前元素數 | 現有元素個數,用來分辨空與滿 |
| capacity | 容量 | 陣列總格數 |
| modulo (%) | 取餘數 | 除完剩下的數,讓 index 繞回開頭 |
| circular queue | 環形佇列 | 陣列頭尾視為相接的佇列 |
