## Linked List 基礎：節點、指標與 dummy head 技巧 · 第 2 步

### 節點裡到底裝了什麼
每個節點（node）只裝兩件事：值（value）與指向下一個節點的引用（reference / pointer）。可以想成一節火車車廂：車廂裝貨物（值），車廂尾巴的鉤子勾住下一節車廂。整條 Linked List 就是靠這些鉤子把散落各處的車廂串成一列。

### 插入新節點：只要改兩個鉤子
在 n0 與 n1 之間插入新節點 p，陣列做法是把 n1 之後所有元素往後搬一格；Linked List 只要讓 p.next 指向 n1、再讓 n0.next 指向 p，兩個引用改完即完成插入，跟串列長度無關，時間複雜度 O(1)。

> ⚠ 最容易搞錯的地方：O(1) 只指「插入這一步」，前提是手上已經有指向 n0 的指標。若要從頭節點找到 n0 才插入，找的過程本身仍是 O(n)。

### 跟陣列比，為什麼差這麼多
陣列插入要 O(n) 是因為記憶體位置連續固定，插入中間就要搬移後面所有元素；Linked List 節點本來就散落各處靠引用相連，插入不需要移動任何舊節點，只需重新接一次鉤子。

```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int val) {
        this.val = val;
    }
}

// 在 n0 和 n1 之間插入 p
p.next = n1;
n0.next = p;
```

### 這東西用在哪
**對寫程式的人**：需要頻繁在中間插入/刪除大量資料而非用 index 隨機存取時選 Linked List（例如 LRU Cache、瀏覽器上一頁/下一頁、播放清單插入下一首）；但插入的 O(1) 優勢只在已經有目標位置指標時成立，否則仍要先花 O(n) 走過去。

**對產品端的人**：若功能是「拖曳插入清單中間、資料再多也不變慢」，背後多半是類似 Linked List 的結構；若「資料一多，插入/刪除就明顯變慢、要做分頁」，背後多半是陣列類結構在搬移資料——可以問工程師「這個插入功能，資料量長到十萬筆會不會變慢？」

### 動手寫：LeetCode #2807 Insert Greatest Common Divisors in Linked List（Medium）
[題目連結](https://leetcode.com/problems/insert-greatest-common-divisors-in-linked-list/)

題目：在每對相鄰節點之間插入一個新節點，值為兩節點值的 gcd。

解法步驟：
1. 指標 cur 從頭走訪。
2. 算 cur 與 cur.next 的 gcd，建立新節點 node。
3. node.next = cur.next；cur.next = node（今天的插入技巧）。
4. cur = node.next，跳過新節點繼續走。

複雜度：時間 O(n log m)（每個節點都要跑一次輾轉相除法）；空間 O(1) 額外空間（新節點算輸出，不算額外空間）。

```java
class Solution {
    public ListNode
    insertGreatestCommonDivisors(
        ListNode head
    ) {
        ListNode cur = head;
        while (cur.next != null) {
            int g = gcd(
                cur.val,
                cur.next.val
            );
            ListNode node =
                new ListNode(g);
            // 插入節點到中間
            node.next = cur.next;
            cur.next = node;
            // 跳到下一組節點
            cur = node.next;
        }
        return head;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int t = b;
            b = a % b;
            a = t;
        }
        return a;
    }
}
```

### 今日術語表
| 術語 | 定義 |
|---|---|
| Node（節點） | 裝著「值」與「指向下一個節點的引用」的單位 |
| Reference / Pointer（引用／指標） | 記錄另一個節點記憶體位置的值，靠它跳到下一個節點 |
| Head Node（頭節點） | 整條串列的第一個節點，常拿來代稱整條串列 |
| Insertion（插入操作） | 把新節點加進串列，Linked List 中只需改兩個引用 |
