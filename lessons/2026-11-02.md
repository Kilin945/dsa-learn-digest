## Binary Tree 基礎：節點、深度與陣列表示法 · 第 2 步

### Array Representation of a Perfect Binary Tree

不用指標，只靠一個陣列加一條公式，也能存下一棵樹。

![完美二元樹的陣列表示](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/array_representation_of_tree.assets/array_representation_binary_tree.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

把完美二元樹（每層都填滿）按層序走訪（由上到下、每層由左到右）的順序存進陣列，每個節點得到唯一的索引。若某節點索引為 i，左子節點索引為 2i + 1，右子節點索引為 2i + 2，這條映射公式的角色就等於鏈結串列中的節點引用（指標）。

**公式怎麼來**：排在索引 i 前面的 i 個節點共生出 2i 個孩子，占掉索引 1 到 2i，所以索引 i 的左孩子是 2i + 1，右孩子是 2i + 2。反推父節點索引是 (i - 1) / 2（整數除法）。

**注意**：公式只在沒有空位的完美二元樹上保證成立；中間有缺口時，單靠層序序列無法確定樹形。

```java
// 陣列表示的完美二元樹
int[] tree = {1, 2, 3, 4, 5, 6, 7};

int i = 1;
// 左子節點索引
int left = 2 * i + 1;
// 右子節點索引
int right = 2 * i + 2;
// 父節點索引（整數除法自動捨去）
int parent = (i - 1) / 2;
```

### 這東西用在哪

- 寫程式：Java 的 PriorityQueue 底層就是用陣列存的二元樹（堆積）。形狀緊密時陣列比節點物件省空間、記憶體連續；形狀稀疏時會浪費大量空位，應改用節點加引用。
- 產品端：任務排程、派單這類「永遠先處理最緊急」的功能背後常是這種結構。層數隨資料量翻倍才加一層，百萬筆約 20 層，所以資料量大幅成長速度只慢一點點；前提是樹要保持填得很滿，若偏一邊長，層數會等於筆數。

### LeetCode

[#958 Check Completeness of a Binary Tree](https://leetcode.com/problems/check-completeness-of-a-binary-tree/)（Medium）

**題目在說什麼**：判斷一棵二元樹是不是完全二元樹（除最底層外都填滿，最底層從左連續排）。

**怎麼用今天學的東西解**：

1. 遞迴數出節點總數 n。
2. 完全二元樹存進陣列時索引剛好是 0 到 n-1。
3. 走訪時根的假想索引為 0，左孩子 2i+1、右孩子 2i+2。
4. 任一節點的假想索引大於等於 n，代表有空洞，回傳 false。
5. 全部走完沒超出，回傳 true。

**複雜度**：時間 O(n)，數節點與檢查索引各走一遍整棵樹；空間 O(h)，只有遞迴堆疊，深度為樹高，最差偏一邊時 h 等於 n。

```java
class Solution {
  public boolean isCompleteTree(
      TreeNode root) {
    int n = count(root);
    return check(root, 0, n);
  }

  // 數節點：自己 + 左 + 右
  private int count(TreeNode node) {
    if (node == null) return 0;
    return 1 + count(node.left)
        + count(node.right);
  }

  // i 是這個節點「假想的陣列索引」
  private boolean check(
      TreeNode node, int i, int n) {
    if (node == null) return true;
    // 索引超出 n：表示中間有空洞
    if (i >= n) return false;
    return check(node.left, 2*i+1, n)
        && check(node.right, 2*i+2, n);
  }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Array | 陣列 | 一排連續、有編號（從 0 開始）的格子 |
| Index | 索引 | 陣列格子的編號 |
| Level-order traversal | 層序走訪 | 從根開始一層一層往下，每層由左到右讀出節點 |
| Perfect binary tree | 完美二元樹 | 每一層節點都被填滿的二元樹 |
| Mapping formula | 映射公式 | 由一個編號算出另一個編號的算式：2i+1、2i+2、(i-1)/2 |
| Complete binary tree | 完全二元樹 | 只有最底層可不滿，且最底層從左至右連續填 |
