## 字串 String：不可變性、StringBuilder 與字元陣列的關係 · 第 1 步

### 今天教的概念：String Immutability（不可變性）

Java 的 String 一旦建立，內容就不能被就地修改。像 `concat()`、`replace()`、
`substring()` 這些看起來像是在「修改」字串的方法，實際上都是在背後重新配置
一塊新的記憶體、把結果放進去，再回傳這個新物件的參考（reference）。原本的
字串物件完全沒被動到。

因為 String 本身不能就地修改，如果真的需要在原地一個字一個字改動文字（例如
翻轉字串），Java 的做法是先把字串轉成 `char[]`（字元陣列），陣列裡每一格都
可以直接覆寫，這跟 String 的不可變正好相反。

⚠ 最容易搞錯的地方：用 `==` 比較兩個 String 變數，比的是兩個變數是不是指向
同一塊記憶體，不是比內容是否一樣；要比內容永遠要用 `.equals()`。

```java
String a = "hello";
// a 沒變，還是 hello
String b = a.concat(" world");
// b 是新字串 hello world
System.out.println(a);
// 印出 hello
System.out.println(b);
// 印出 hello world
```

### 這東西用在哪

- 對工程師：在迴圈裡用 `+` 或 `concat` 反覆拼字串，每次都建立一個新的字串
  物件，n 次迴圈就是 O(n²)。下一步會教用 StringBuilder 這種可變的暫存空間
  解決這個問題。
- 對產品端：功能是「把很多小段文字組合成一份長文字」（通知信、報表、對話
  紀錄）時，若工程師沒注意到字串不可變，就可能寫出筆數一多就明顯變慢的功能。
  可以直接問工程師：「這裡是不是在迴圈裡用加號組字串，資料量大時會不會變慢？」

### LeetCode 練習：[#344 Reverse String](https://leetcode.com/problems/reverse-string/)（Easy）

題目：給一個字元陣列 char[]，原地把它反轉，不能回傳新陣列。

解法：因為 String 不可變，題目故意給 char[] 讓你能原地改；用左右兩個指標，
交換指到的字元，指標分別往中間移動，直到相遇。

複雜度：時間 O(n)（兩個指標合計只走陣列一次），空間 O(1)（沒有額外開陣列）。

```java
class Solution {
    public void reverseString(char[] s) {
        int left = 0, right = s.length - 1;
        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            left++;
            right--;
        }
    }
}
```

### 今日術語表

| 術語 | 定義 |
|---|---|
| Immutable 不可變 | 物件建立後內容無法被修改，「修改」方法其實回傳新物件 |
| char[] 字元陣列 | 把字串拆成可逐格修改的陣列，用於需要就地改動文字時 |
| concat() 字串串接 | 把兩個字串接起來、回傳新字串，原字串不受影響 |
