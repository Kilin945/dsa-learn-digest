## 二元樹走訪：前序/中序/後序 DFS 與 BFS 層序 · 第 3 步

### Iterative DFS: Replace Recursion with an Explicit Stack

![前序走訪的遞迴過程](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_tree_traversal.assets/preorder_step1.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

圖說：前序走訪的遞迴過程分成「遞」（開啟新方法、訪問下一個節點）與「迴」（函式返回、當前節點訪問完畢）兩個相反方向的部分。電腦背後用一疊待辦記錄「遞」與「迴」，今天把它搬到檯面上自己管理。

**遞迴背後的隱形堆疊**：遞迴 DFS 一直都在用呼叫堆疊（call stack），堆疊是後進先出（LIFO）的容器。

**自己準備堆疊**：迭代 DFS 把 BFS 的佇列換成堆疊，每輪彈出一個節點、訪問、再推入子節點。

**手動走一遍前序**：樹為 1(左 2(4,5)、右 3)，過程如下，輸出 1 2 4 5 3。

```
開始：        [1]
彈 1，推 3、2 → [3, 2]
彈 2，推 5、4 → [3, 5, 4]
彈 4（無子）  → [3, 5]
彈 5（無子）  → [3]
彈 3（無子）  → []
```

> ⚠ 要先推右子、再推左子；順序反了會走出先右後左的鏡像，程式不會報錯但答案是錯的。

```java
Deque<TreeNode> stack =
    new ArrayDeque<>();
stack.push(root);
while (!stack.isEmpty()) {
    TreeNode node = stack.pop();
    // 在這裡訪問 node
    // 先推右子、再推左子
    if (node.right != null)
        stack.push(node.right);
    if (node.left != null)
        stack.push(node.left);
}
```

一句話：遞迴 DFS 和迭代 DFS 路線一樣，差別只在堆疊是系統管還是自己管。

### 這東西用在哪

- 對寫程式的人：深度可控用遞迴；深度不可預期（可能退化成一條線）用顯式堆疊，避免 StackOverflowError，堆疊放在 heap，上限大得多。代價是程式碼較長，中序、後序的迭代寫法更難。
- 對產品端的人：資料夾、留言串、組織圖這類層層巢狀的功能背後多半是樹。耗時跟節點總數成正比；真正的風險是巢狀層數太深導致崩潰而非變慢，所以常見限制回覆層數。資安上，攻擊者可能故意送極深的巢狀資料。可問工程師：最深支援幾層？超過會怎樣？

### 動手寫 · LeetCode

[#144 Binary Tree Preorder Traversal](https://leetcode.com/problems/binary-tree-preorder-traversal/)（Easy）

題目：給二元樹根節點，依根、左、右的順序回傳所有節點的值。

解題步驟：
1. 根為空回傳空清單。
2. 把根推進堆疊。
3. 堆疊不空時彈出節點並加入結果。
4. 先推右子、再推左子。
5. 結束後結果即為前序順序。

複雜度：時間 O(n)，每個節點推入、彈出各一次；空間 O(h)，堆疊同時存在的節點數與樹高同量級，最壞 O(n)。

```java
public List<Integer> preorderTraversal(
        TreeNode root) {
    List<Integer> res = new ArrayList<>();
    if (root == null) return res;
    Deque<TreeNode> stack =
        new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        // 彈出時就訪問
        res.add(node.val);
        // 先推右子，後進先出
        if (node.right != null)
            stack.push(node.right);
        // 再推左子，下一輪先彈它
        if (node.left != null)
            stack.push(node.left);
    }
    return res;
}
```

### 術語表

| 術語 | 白話定義 |
| --- | --- |
| Stack 堆疊 | 後進先出的容器，像一疊盤子。 |
| LIFO 後進先出 | 最後放進去的最先被拿出來。 |
| Call stack 呼叫堆疊 | 電腦記錄哪些函式做到一半、做完要回哪裡的記憶體，遞迴靠它運作。 |
| Iterative 迭代 | 用迴圈重複做事，不讓函式呼叫自己。 |
| push / pop | 放到堆疊頂端／從頂端拿出。 |
| StackOverflowError 堆疊溢位 | 遞迴太深、呼叫堆疊裝不下時 Java 丟出的錯誤。 |
