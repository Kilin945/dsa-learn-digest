## 樹的經典題型：深度、直徑、最近共同祖先 LCA · 第 3 步

### Lowest Common Ancestor (LCA) in a Binary Tree

**LCA 是什麼**：祖先（ancestor）是從某節點一路往根走經過的所有節點（含自己）。p、q 的共同祖先中最深的那一個就是 LCA。比喻：組織圖裡兩位員工第一個共同的上司。

**遞迴要回傳什麼**：find(node) 回傳「這棵子樹裡有沒有找到 p 或 q」。空節點回傳 null；節點本身是 p 或 q 就回傳自己。

**三種情況**：
1. 左右都回報有找到 → 當前節點就是 LCA，回傳自己。
2. 只有一邊有 → 把那一邊往上傳。
3. 兩邊都沒有 → 回傳 null。

> ⚠ 撞到 p 或 q 就立刻回傳不會漏：若另一個點在它底下，它本來就是 LCA；否則另一個點會在別條路被找到並於分岔點匯合。前提是 p、q 一定存在。

### 這東西用在哪

- 寫程式的人：檔案系統共同資料夾、組織圖共同主管、留言串共同源頭、Git merge-base。單次查詢遞迴 O(n)；大量重複查詢才需要預處理（如倍增法）。
- 產品端：「共同最近主管」類功能背後多半是樹上找 LCA；最直接做法每次掃全樹，人數越多單次越慢，批次大量配對時可能變慢，可問工程師是否有預處理。

### LeetCode

[#236 Lowest Common Ancestor of a Binary Tree](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)（Medium）

解法步驟：
1. 節點為 null 回傳 null；為 p 或 q 回傳該節點。
2. 遞迴問左、右子樹。
3. 左右都非 null → 回傳當前節點。
4. 否則回傳非 null 的那一邊。

複雜度：時間 O(n)（每個節點最多造訪一次）；空間 O(h)（遞迴堆疊深度為樹高）。

```java
class Solution {
    public TreeNode
            lowestCommonAncestor(
            TreeNode root,
            TreeNode p, TreeNode q) {
        // 走到底，或剛好撞到 p 或 q
        if (root == null || root == p
                || root == q) {
            return root;
        }
        TreeNode left =
            lowestCommonAncestor(
                root.left, p, q);
        TreeNode right =
            lowestCommonAncestor(
                root.right, p, q);
        // 左右都找到：我就是分岔點
        if (left != null
                && right != null) {
            return root;
        }
        // 只有一邊找到，往上傳
        return left != null
            ? left : right;
    }
}
```
