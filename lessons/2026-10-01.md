## Stack 堆疊：後進先出、括號配對與單調堆疊 · 第 4 步

### Monotonic Stack：讓堆疊保持順序

**先講結論**

單調堆疊（Monotonic Stack）不是新的資料結構，而是堆疊的一種用法：照樣只用 push 和 pop，但多訂一條規矩——堆疊裡的元素從底到頂，必須永遠維持遞增或遞減。新元素要進來之前，先把頂端會破壞順序的元素全部彈掉，再放自己進去。

**它在解什麼問題**

最典型的題目是「下一個更大元素」（Next Greater Element）：每個位置往右找第一個比自己大的元素。暴力解每個位置都往右掃一遍，最壞 O(n²)。關鍵觀察：一旦某個元素等到了比它大的，它就結算完畢，不用再留在堆疊裡；還在等的元素由底到頂不會變大，這就是遞減單調堆疊。

**跑一遍**

氣溫 [73,74,75,71,69,72,76,73]（堆疊實際存索引，這裡畫成溫度）：

```
第0天 73：push → [73]
第1天 74：73 出、答案1 → [74]
第2天 75：74 出、答案1 → [75]
第3天 71：push → [75,71]
第4天 69：push → [75,71,69]
第5天 72：69,71 出 → [75,72]
第6天 76：72,75 出 → [76]
第7天 73：push → [76,73]
最後 76,73 沒等到 → 答案 0
答案：[1,1,4,2,1,1,0,0]
```

**⚠ 最容易搞錯**：for 裡面包 while 不等於 O(n²)。每個元素最多 push 一次、pop 一次，總動作不超過 2n，整體 O(n)。

通用骨架：

```
for (每個新元素 x) {
    while (堆疊非空 且 頂端 < x)
        pop 並結算頂端
    push x
}
```

一句話：新元素先把不合格的頂端彈掉並結算，再自己進去，每個元素只進出一次，一次掃描解決「下一個更大」。

深入官方文件：[Java Deque API](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Deque.html)

### 這東西用在哪

**對寫程式的人**：看到「下一個更大／更小」「還要等多久」「左右第一個…」就想單調堆疊，它把內層迴圈拿掉，O(n²) 變 O(n)。需要距離時存索引不存值；掃完剩下的元素代表右邊沒有更大的，要給預設值。

**對產品端的人**：「距離上次更嚴重的事件幾天」「股價幾天後漲回來」這類功能背後常是它。一萬筆資料暴力版約一億次比較、單調堆疊約兩萬次；十萬筆時暴力版是一百億次，會從有點慢變成跑不完。可問工程師：「這個計算是一次掃完，還是每筆都回頭重找？資料變十倍會慢幾倍？」

### 動手寫 · LeetCode

[#739 Daily Temperatures](https://leetcode.com/problems/daily-temperatures/)（Medium）

**題目在說什麼**：給每天的氣溫，對每一天回答還要等幾天才會遇到更熱的一天；之後沒有更熱的就答 0。

**解法步驟**

1. 建一個放日子索引的堆疊，裡面的日子都在等更熱的一天。
2. 由左到右掃每一天 i。
3. 堆疊不空且今天比頂端那天熱，就彈出頂端 prev，ans[prev] = i - prev。
4. 彈完後把 i push 進堆疊。
5. 掃完後堆疊剩下的答案維持 0。

**複雜度**

- 時間 O(n)：每天最多 push 一次、pop 一次，總動作約 2n。
- 空間 O(n)：氣溫一路下降時所有日子都留在堆疊，再加上答案陣列。

```java
import java.util.*;

class Solution {
    public int[] dailyTemperatures(
            int[] t) {
        int n = t.length;
        int[] ans = new int[n];
        // 堆疊存索引，不存溫度
        Deque<Integer> st =
            new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            // 比今天冷的都結算掉
            while (!st.isEmpty()) {
                int prev = st.peek();
                // 頂端比今天熱，停
                if (t[i] <= t[prev])
                    break;
                st.pop();
                ans[prev] = i - prev;
            }
            // 今天先進堆疊等更熱的
            st.push(i);
        }
        return ans;
    }
}
```

### 術語表

- **Monotonic Stack 單調堆疊**：堆疊由底到頂保持遞增或遞減，新元素進來前先彈掉會破壞順序的頂端。
- **Next Greater Element 下一個更大元素**：對每個位置，往右找第一個比它大的元素。
- **Index 索引**：元素在陣列裡的編號，從 0 開始，可用來算相隔距離。
- **peek 偷看頂端**：只看堆疊頂端，不拿走。
- **Brute force 暴力解**：每個位置都重新掃一遍的做法，簡單但資料一多就慢。
