## 圖的表示法：鄰接矩陣與鄰接表的取捨 · 第 1 步

### Two Ways to Store a Graph: Adjacency Matrix vs Adjacency List

圖（graph）由頂點（vertex）和邊（edge）組成。寫程式前要先決定怎麼把圖存進記憶體，最常見的有兩種表示法。

![圖的鄰接矩陣表示](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_graph/graph.assets/adjacency_matrix.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**鄰接矩陣（adjacency matrix）**：用 n × n 的矩陣表示圖，每一行（列）代表一個頂點。設鄰接矩陣為 M、頂點串列為 V，M[i, j] = 1 表示頂點 V[i] 與 V[j] 之間有邊，M[i, j] = 0 表示無邊。

- 簡單圖中頂點不會與自身相連，主對角線上的元素沒有意義。
- 無向圖的兩個方向等價，所以矩陣關於主對角線對稱。
- 把 1 和 0 換成權重，就能表示有權圖。
- 查單一條邊 O(1)；空間 O(n²)。

![圖的鄰接表表示](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_graph/graph.assets/adjacency_list.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**鄰接表（adjacency list）**：用 n 條鏈結串列表示圖，第 i 條串列對應頂點 i，儲存該頂點所有的鄰接頂點。只記真的存在的邊，空間約 O(n + m)（m 為邊數）；查某條邊要在串列中找，最壞掃完該頂點所有鄰居。

**取捨**：稀疏圖（邊遠少於可能的最大邊數）選鄰接表；邊很密且常要判斷兩點有沒有邊，才考慮鄰接矩陣。

**易錯**：矩陣的 O(1) 只對「查某一條邊」成立；要「列出某頂點所有鄰居」，矩陣得掃一整列 O(n)，鄰接表只要走該頂點的串列。

```java
// 鄰接矩陣：n x n 的二維陣列
int[][] m = new int[n][n];
// 加邊 0-1（無向，兩個方向都要填）
m[0][1] = 1;
m[1][0] = 1;

// 鄰接表：每個頂點一個串列
List<List<Integer>> g =
    new ArrayList<>();
for (int i = 0; i < n; i++)
  g.add(new ArrayList<>());
// 加邊 0-1，同樣兩個方向
g.get(0).add(1);
g.get(1).add(0);
```

### 這東西用在哪

- 寫程式：圖題通常給邊清單，先轉成鄰接表再走訪；頂點多、邊少時用矩陣會浪費 n × n 記憶體。
- 產品端：好友、推薦、路線等功能背後多半是圖；100 萬用戶若用表格存要一兆格，所以大型系統幾乎都是通訊錄式（鄰接表）。可問工程師：「有多少點、平均每點幾條邊？用哪種存法？」

### LeetCode：[#1971 Find if Path Exists in Graph](https://leetcode.com/problems/find-if-path-exists-in-graph/)（Easy）

**題意**：給 n 個頂點與無向邊清單，問能否從 source 走到 destination。

**解法**：

1. 把邊清單轉成鄰接表，建 n 條空串列。
2. 每條邊 [a, b] 兩個方向都加。
3. 從 source 用佇列逐個拜訪鄰居。
4. 用 seen 避免重複；遇到 destination 回傳 true，否則 false。

**複雜度**：時間 O(n + m)，建表 n + m、走訪每點一次每邊兩次；空間 O(n + m)，鄰接表加 seen 與佇列。

```java
// 需要 import java.util.*;
class Solution {
  public boolean validPath(int n,
      int[][] edges, int source,
      int destination) {
    // 建鄰接表：n 條空串列
    List<List<Integer>> g =
        new ArrayList<>();
    for (int i = 0; i < n; i++) {
      g.add(new ArrayList<>());
    }
    // 無向邊：兩個方向都加
    for (int[] e : edges) {
      g.get(e[0]).add(e[1]);
      g.get(e[1]).add(e[0]);
    }
    // 記錄走過的點
    boolean[] seen = new boolean[n];
    Deque<Integer> q =
        new ArrayDeque<>();
    q.add(source);
    seen[source] = true;
    while (!q.isEmpty()) {
      int cur = q.poll();
      if (cur == destination) {
        return true;
      }
      // 逐個拜訪 cur 的鄰居
      for (int nb : g.get(cur)) {
        if (!seen[nb]) {
          seen[nb] = true;
          q.add(nb);
        }
      }
    }
    return false;
  }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Graph | 圖 | 由頂點和邊組成的非線性資料結構 |
| Vertex | 頂點 | 圖中的一個個體 |
| Edge | 邊 | 連接兩個頂點的線 |
| Undirected / Directed | 無向／有向 | 邊是雙向關係或有方向 |
| Degree | 度 | 一個頂點擁有的邊數；有向圖分入度與出度 |
| Path | 路徑 | 從 A 到 B 經過的邊的序列 |
| Adjacency matrix | 鄰接矩陣 | n × n 表格，1 表示有邊、0 表示無邊 |
| Adjacency list | 鄰接表 | n 條串列，第 i 條記錄頂點 i 的所有鄰居 |
| Sparse graph | 稀疏圖 | 邊遠少於可能最大邊數的圖 |
