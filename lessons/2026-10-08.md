## Queue 佇列與 Deque：先進先出、環形佇列與雙端佇列 · 第 5 步

### Queue vs Deque: Wrap-up and When to Use Which

![佇列的先入先出規則](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_stack_and_queue/queue.assets/queue_operations.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

佇列是元素排成一條線、先進先出的結構。新元素從佇列尾「入列」，佇列首的元素「出列」。

![雙向佇列的操作](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_stack_and_queue/deque.assets/deque_operations.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

普通佇列只能刪頭、增尾；雙向佇列頭尾都能新增與刪除。

**四天學了什麼**：佇列、環形陣列實作、雙端佇列、鏈結串列實作。不管底層是陣列還是鏈結串列，端點新增或刪除都是 O(1)，因為只碰頭或尾。

**該選哪一個**：只排隊就宣告 Queue，兩端都要進出就宣告 Deque，實作統一先選 ArrayDeque（不允許 null）。

**典型應用**：列印工作、請求排隊、訊息佇列、BFS（佇列）；滑動視窗（雙端佇列）。

**注意**：ArrayDeque 的 push 加在頭部、offer 加在尾部，混用會讓順序悄悄反過來。

```java
Queue<Integer> q = new ArrayDeque<>();
// 排隊：尾進、頭出
q.offer(1);
q.poll();

Deque<Integer> d = new ArrayDeque<>();
// 兩端都能進出
d.offerFirst(1);
d.pollLast();
```

### 這東西用在哪

- 寫程式：依序處理用 Queue，兩端取出用 Deque；別用 ArrayList.remove(0) 當佇列，n 次出列會變 O(n²)。
- 產品端：「排隊中前面還有 N 人」多半是佇列；佇列本身很快，會垮的是進來的速度長期大於處理的速度（一萬筆、每筆一秒，最後一筆要等約 2.8 小時）。

### LeetCode

[#933 Number of Recent Calls](https://leetcode.com/problems/number-of-recent-calls/)（Easy）

- 題意：每次 ping(t) 回傳 [t-3000, t] 內的請求數。
- 解法：請求時間從佇列尾入列；佇列首小於 t - 3000 就出列；佇列長度即答案。
- 時間 O(1) 攤還（每個時間戳最多入列、出列各一次）；空間 O(W)（只留 3000 毫秒內的請求）。

```java
class RecentCounter {
    // 存放每次 ping 的時間
    private Queue<Integer> q;

    public RecentCounter() {
        q = new ArrayDeque<>();
    }

    public int ping(int t) {
        // 新請求從佇列尾入列
        q.offer(t);
        // 太舊的從佇列首出列
        while (q.peek() < t - 3000) {
            q.poll();
        }
        // 剩下的都在 [t-3000, t] 內
        return q.size();
    }
}
```

### 術語表

| 術語 | 定義 |
|---|---|
| FIFO 先入先出 | 先進去的先出來，像排隊 |
| Deque 雙端佇列 | 頭尾兩端都能新增與刪除的佇列 |
| ArrayDeque | Java 內建、環形陣列實作的 Deque，也能當 Queue 與堆疊 |
| Message Queue 訊息佇列 | 把待處理工作排隊，由後面程式依序取出 |
| BFS 廣度優先搜尋 | 從起點一層層往外找，靠佇列記住下一批要走的點 |
| Sliding Window 滑動視窗 | 固定大小的範圍沿資料往後滑 |
