## HashMap / HashSet：O(1) 查找的原理與代價 · 第 5 步

### HashSet: a HashMap with only keys

![雜湊表的抽象表示](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_hashing/hash_map.assets/hash_table_lookup.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

圖中的雜湊表在 key 與 value 之間建立對應，輸入 key 即可在 O(1) 取得 value（例：學號是 key、姓名是 value）。把 value 那一側拿掉、只留 key，問題就從「這個學號對應誰」變成「這個學號有沒有出現過」，這就是 HashSet。

**HashSet 是什麼**

Set（集合）是不允許重複元素的容器。HashSet 只存 key，專門回答「這個東西在不在裡面」。

**Java 裡怎麼做到**

Java 的 HashSet 內部包著一個 HashMap：add(x) 等於 put(x, 共用的假值)。因此雜湊函式、衝突處理、負載因子與擴容、hashCode／equals 合約全部原封不動適用。

**三個常用操作**

add、contains、remove 平均都是 O(1)。add 新放入回傳 true、已存在回傳 false，一次操作同時完成檢查與記錄。

> ⚠ 最容易搞錯：List.contains 是 O(n)（逐一比對），拿 List 做去重或存在檢查，整體會變成 O(n²)；頻繁問「有沒有」請用 HashSet。

```java
Set<String> set = new HashSet<>();

// 第一次放入，回傳 true
set.add("A");

// 重複放入，回傳 false，集合不變
set.add("A");

// 查有沒有，平均 O(1)
set.contains("A");

// 移除，平均 O(1)
set.remove("A");
```

**一句話帶走：** HashSet 就是只存 key 的 HashMap，專門以平均 O(1) 回答「有沒有」。

### 這東西用在哪

- 寫程式的人：陣列去重、找重複元素、記錄走訪過的節點、名單交集差集、黑名單比對；把 O(n²) 的暴力檢查壓成 O(n)。用錯代價：拿 List 當 Set 會變慢；自訂物件 key 沒寫好 hashCode／equals 會查不到或重複放入。
- 產品端的人：「同一個東西不能重複」的功能（匯入名單剔除重複 Email、優惠券每人限領一次、已讀不再推）背後多半是集合。用集合時資料長大十倍檢查時間幾乎不變；逐筆掃整份名單則一萬筆約一億次比對、一百萬筆約一兆次。代價是資料全放記憶體（空間換時間），上億筆就要改走資料庫索引等方案。可問工程師：「這個重複檢查是逐筆掃，還是用集合？資料長到十倍會怎樣？」

### 動手寫 · LeetCode

[#217 Contains Duplicate](https://leetcode.com/problems/contains-duplicate/)（Easy）

**題目在說什麼：** 給整數陣列 nums，若有任何數字出現兩次以上回傳 true，否則回傳 false。

**怎麼用今天學的東西解：**

1. 準備空的 HashSet seen，記錄已看過的數字。
2. 走訪陣列，取得每個 x。
3. seen.add(x) 回傳 false 代表已存在，直接回傳 true。
4. 全部走完沒重複，回傳 false。

**複雜度：**

- 時間 O(n)：只走訪一次，每次 add 平均 O(1)。
- 空間 O(n)：最壞情況 n 個數字都不重複，seen 要全存。

```java
class Solution {
    public boolean containsDuplicate(
            int[] nums) {
        // 記錄已經看過的數字
        Set<Integer> seen =
            new HashSet<>();
        for (int x : nums) {
            // 已存在就會回傳 false
            if (!seen.add(x)) {
                return true;
            }
        }
        return false;
    }
}
```

### 術語表

| 術語 | 中文 | 白話定義 |
|---|---|---|
| HashSet | 雜湊集合 | 只存 key、不存 value 的雜湊表，快速判斷在不在裡面 |
| Set | 集合 | 不允許重複元素的容器 |
| Deduplication | 去重 | 剔除重複資料，只留一份 |
| Membership test | 存在性檢查 | 問某東西在不在集合裡，答案只有是或否 |
| Space-time trade-off | 空間換時間 | 多用記憶體換取更快速度 |
