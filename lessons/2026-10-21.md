## 雜湊函式與負載因子：hashCode、擴容與 rehash · 第 1 步

### Hash Function & hashCode: Turning a Key into a Bucket Number

![雜湊衝突的最佳情況與最差情況](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_hashing/hash_algorithm.assets/hash_collision_best_worst_condition.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**圖在講什麼**：鏈式位址雜湊表中，理想情況下鍵值對均勻分佈在各個桶，查詢效率最佳；最差情況下所有鍵值對都存進同一個桶，時間複雜度退化成 O(n)。開放定址與鏈式位址只保證衝突時能正常運作，無法減少衝突，所以要靠雜湊函式分得均勻。

**雜湊函式在做什麼**：雜湊函式是一台固定的算號機，輸入 key，輸出整數；Java 的 `hashCode()` 就是這個角色。整數除以桶數取餘數，得到桶編號。同一個 key 永遠算出同一個桶，所以找資料靠「算」，不用逐筆比對。

**好的雜湊函式**：標準只有一個，讓不同的 key 均勻散到各個桶。最壞的例子是永遠回傳固定數字。

**為什麼均勻重要**：n 筆資料、m 個桶，均勻時每桶平均 n/m 筆，查找平均 O(1)；全擠同一桶則要逐筆比對，O(n)。

**易錯**：相等的物件 hashCode 必須相同。改了 equals 卻沒改 hashCode，相等的物件會被算到不同桶，導致查不到。

```java
// 步驟1：key 變成一個整數
int h = key.hashCode();
// 步驟2：整數變成桶編號
int index =
    Math.floorMod(h, capacity);

// "ab" 的 hashCode 怎麼算
int h = 0;
// 'a' 是 97，'b' 是 98
h = 31 * h + 'a';
h = 31 * h + 'b';
// h = 31*97 + 98 = 3105
// capacity=16 時，3105 % 16 = 1
// 所以 "ab" 會放進 1 號桶

// 壞例子：永遠回傳 42
public int hashCode() {
    return 42;
}
// 所有物件進同一桶，退化成 O(n)
```

**一句話**：雜湊函式把 key 算成桶編號，算得越均勻越接近 O(1)，全擠同一桶就退化成 O(n)。

### 這東西用在哪

- 寫程式的人：自訂類別當 key 時，equals 與 hashCode 用同一組欄位（可用 `Objects.hash`）。不一致會查不到，太集中會很慢。
- 產品端：會員查詢、去重、快取、session 多半是雜湊表。用來分組的欄位值要夠分散，否則資料變多就變慢。可問工程師「資料變十倍，最擠的那一組會多大？」。資安上有 hash flooding 攻擊，故意送一堆算到同一桶的 key。

### LeetCode

[#49 Group Anagrams](https://leetcode.com/problems/group-anagrams/)（Medium）

- 題意：把字母相同、順序不同的字串歸成一組。
- 解法：字串排序後當 key，HashMap 的 value 存原字串清單，最後回傳所有 value。
- 複雜度：時間 O(n · k log k)，因為每個字串排序一次；空間 O(n · k)，因為 map 存下全部字串。

```java
class Solution {
  public List<List<String>>
      groupAnagrams(String[] strs) {
    Map<String, List<String>> map =
        new HashMap<>();
    for (String s : strs) {
      char[] cs = s.toCharArray();
      // 排序後相同，就是同一組
      Arrays.sort(cs);
      String key = new String(cs);
      // 沒有這組就先建立空清單
      map.computeIfAbsent(key,
          k -> new ArrayList<>())
         .add(s);
    }
    // 每個 value 就是一組
    return new ArrayList<>(map.values());
  }
}
```
