## Queue 佇列與 Deque：先進先出、環形佇列與雙端佇列 · 第 3 步

### Deque (Double-Ended Queue)

佇列只能一頭進、一頭出；雙端佇列兩頭都能進、都能出。

![雙向佇列的操作](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_stack_and_queue/deque.assets/deque_operations.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

一般佇列只能刪除頭部元素、在尾部新增元素；雙向佇列（deque）允許在頭部和尾部都新增或刪除元素，頭尾各兩種動作，共四種。

**概念**

- 佇列是尾進頭出；deque 把規則放寬，兩端都能進出，可以當佇列，也可以當堆疊用。
- Java 的 ArrayDeque 同時實作 Queue 與 Deque。offerFirst/offerLast 新增，pollFirst/pollLast 取出並刪除，peekFirst/peekLast 只看不拿；poll、peek 遇空回傳 null。
- 底層可用環形陣列（尾端寫在 (front + size) % capacity，頭部新增則 front 往左退一格並繞回）或雙向鏈結串列（每個節點記得前後節點）。
- 四個端點操作都是 O(1)：只動頭尾附近的一兩個位置，不搬動中間元素。

```java
Deque<Integer> dq = new ArrayDeque<>();
// 頭部新增：[1]
dq.offerFirst(1);
// 尾部新增：[1, 2]
dq.offerLast(2);
// 頭部新增：[0, 1, 2]
dq.offerFirst(0);
// 看頭：0，看尾：2（不拿出來）
int h = dq.peekFirst();
int t = dq.peekLast();
// 頭部刪除，回傳 0
dq.pollFirst();
// 尾部刪除，回傳 2
dq.pollLast();
```

**⚠ 最容易搞錯的地方**：沒有 First/Last 的舊方法各有預設方向。offer、add 加在尾部，poll、remove 從頭部拿，但 push 加在頭部、pop 從頭部拿。同一個 deque 混用 offer 與 push，順序會跟預期相反。建議一律用方向明確的名字。

### 這東西用在哪

**對寫程式的人**：兩頭都要動的場合選 ArrayDeque，例如滑動視窗、回文檢查、0-1 BFS，也是取代舊 Stack 的建議選擇。若用 ArrayList 在頭部插入或刪除，每次要搬動後面所有元素，是 O(n)。

**對產品端的人**：「只保留最近 N 筆」「可撤回剛剛那一筆」「VIP 插隊到最前面」這類功能背後常是雙端佇列。頭尾操作不隨資料量變慢，一百筆與一百萬筆一樣快；但要找或刪中間某一筆就得逐筆找，量大才會慢。可以問工程師：這個功能只動頭尾嗎？有沒有人會需要動中間？

### 動手寫 · LeetCode

[#641 Design Circular Deque](https://leetcode.com/problems/design-circular-deque/)（Medium）

**題目在說什麼**：做一個容量固定為 k 的環形雙端佇列，支援 insertFront、insertLast、deleteFront、deleteLast、getFront、getRear、isEmpty、isFull。新增與刪除成功回傳 true，失敗回傳 false；getFront、getRear 在空時回傳 -1。

**怎麼用今天學的東西解**

1. 沿用環形陣列：front 記頭的位置、size 記元素個數，cap 為容量。
2. 尾部新增寫在 (front + size) % cap，size 加 1。
3. 頭部新增先讓 front 往左退一格 (front - 1 + cap) % cap，再寫入，size 加 1。
4. 頭部刪除 front 往右一格，size 減 1。
5. 尾部刪除只要 size 減 1。
6. 取尾位置是 (front + size - 1) % cap；空與滿用 size == 0、size == cap 判斷。

**複雜度**

- 時間 O(1)：每個操作只改 front 或 size 並寫入一格，沒有迴圈。
- 空間 O(k)：一開始配好長度 k 的陣列，之後不再變大。

```java
class MyCircularDeque {
  private int[] data;
  private int front;
  private int size;
  private int cap;

  public MyCircularDeque(int k) {
    cap = k;
    data = new int[k];
  }

  public boolean insertFront(int v) {
    if (isFull()) return false;
    // front 往左退一格，必要時繞回尾端
    front = (front - 1 + cap) % cap;
    data[front] = v;
    size++;
    return true;
  }

  public boolean insertLast(int v) {
    if (isFull()) return false;
    // 尾端空位 = front + size 繞回
    int rear = (front + size) % cap;
    data[rear] = v;
    size++;
    return true;
  }

  public boolean deleteFront() {
    if (isEmpty()) return false;
    front = (front + 1) % cap;
    size--;
    return true;
  }

  public boolean deleteLast() {
    if (isEmpty()) return false;
    // 只要 size 減 1，尾巴就退一格
    size--;
    return true;
  }

  public int getFront() {
    if (isEmpty()) return -1;
    return data[front];
  }

  public int getRear() {
    if (isEmpty()) return -1;
    int last = (front + size - 1) % cap;
    return data[last];
  }

  public boolean isEmpty() {
    return size == 0;
  }

  public boolean isFull() {
    return size == cap;
  }
}
```

### 今日術語表

| 術語 | 中文 | 定義 |
| --- | --- | --- |
| Deque | 雙端佇列 | double-ended queue 的縮寫，頭尾兩端都能新增與刪除元素的佇列。 |
| offerFirst / offerLast | 頭／尾新增 | Java 中從頭部、尾部加入元素的方法。 |
| pollFirst / pollLast | 頭／尾取出 | 從頭部、尾部拿出並刪除元素，空的時候回傳 null。 |
| peekFirst / peekLast | 看頭／看尾 | 只看頭部或尾部的元素，不刪除，空的時候回傳 null。 |
| Doubly linked list | 雙向鏈結串列 | 每個節點同時記得前一個與後一個節點的串列，頭尾兩端都能直接操作。 |
