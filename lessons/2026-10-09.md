## HashMap / HashSet：O(1) 查找的原理與代價 · 第 1 步

### Hash Table: Turn a Key into an Index

雜湊表（hash table）透過建立鍵 key 與值 value 之間的對映，讓你輸入一個 key，就能在 O(1) 時間內拿到對應的 value。例如 key 是學號、value 是姓名。

![雜湊表的抽象表示](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_hashing/hash_map.assets/hash_table_lookup.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**雜湊函式的兩步**：1. 用 hash() 算出雜湊值；2. 把雜湊值對桶數量 capacity 取模，得到桶的索引 index。設 capacity = 100、hash(key) = key，則雜湊函式就是 key % 100，例如 12836 % 100 = 36。

![雜湊函式工作原理](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_hashing/hash_map.assets/hash_function.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**為什麼是 O(1)**：算位置只要一次雜湊、一次取模、一次陣列存取，步數固定，與資料量 n 無關。對比陣列掃描是 O(n)。

```java
int capacity = 100;
int key = 12836;
// 取模 (%) 得到桶的編號
int index = key % capacity;

Map<Integer, String> map =
    new HashMap<>();
map.put(12836, "小明");
String name = map.get(12836);
```

**注意**：O(1) 不是只花一步，而是步數不隨 n 增加；而且是理想情況，雜湊衝突會讓速度變差（下一步講）。

### 這東西用在哪

- 寫程式：用 ID、名字、代碼快速查東西，或判斷有沒有重複，用 HashMap／HashSet；在迴圈裡對 List 反覆 contains() 會變 O(n²)。代價是多佔記憶體、不保留順序。
- 產品端：依編號精準查一筆的功能，資料從一百筆到一千萬筆速度幾乎不變；但範圍查詢與排序不是雜湊表的強項，需另外評估。

### LeetCode · [#1 Two Sum](https://leetcode.com/problems/two-sum/)（Easy）

**題目**：在陣列中找兩個不同位置的數字，和等於 target，回傳兩個索引。

**解法**：
1. 準備 HashMap，key 是看過的數字，value 是索引。
2. 逐一走過 nums[i]，算 need = target - nums[i]。
3. 用 get(need) 查搭檔是否出現過（O(1)）。
4. 有就回傳 [搭檔索引, i]。
5. 沒有就把 nums[i] 放進去，繼續。

**複雜度**：時間 O(n)，陣列只走一遍，每次查找與放入都是 O(1)；空間 O(n)，最壞要存 n 個數字。

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums,
                        int target) {
        // key 是數字，value 是它的索引
        Map<Integer, Integer> seen =
            new HashMap<>();
        for (int i = 0;
             i < nums.length; i++) {
            // 需要的搭檔
            int need = target - nums[i];
            // O(1) 查找搭檔出現過沒
            Integer j = seen.get(need);
            if (j != null) {
                return new int[]{j, i};
            }
            // 沒找到，記下自己供後面查
            seen.put(nums[i], i);
        }
        // 題目保證有解，不會走到這
        return new int[0];
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Hash table | 雜湊表 | 用 key 對應 value 的資料結構，查找平均 O(1) |
| Key / Value | 鍵 / 值 | key 是查詢線索，value 是答案 |
| Hash function | 雜湊函式 | 把 key 算成陣列位置的方法：先算雜湊值，再取模 |
| Hash value | 雜湊值 | hash() 算出的數字，尚未壓進陣列範圍 |
| Bucket | 桶 | 陣列的一格，編號即索引 index |
| Capacity | 容量 | 桶的總數，即陣列長度 |
| Modulo (%) | 取模 | 除法取餘數，把大數壓進固定範圍 |
| HashSet | 雜湊集合 | 只存 key 的雜湊表，用來判斷是否出現過、去重 |
