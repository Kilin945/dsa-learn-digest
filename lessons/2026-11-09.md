## Binary Search Tree：中序走訪的有序性與插入刪除 · 第 1 步

### BST Property & Inorder = Sorted Order

![二元搜尋樹](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_search_tree.assets/binary_search_tree.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

二元搜尋樹（binary search tree，BST）滿足兩條：

1. 對於根節點，左子樹中所有節點的值 < 根節點的值 < 右子樹中所有節點的值。
2. 任意節點的左、右子樹也是二元搜尋樹。

![二元搜尋樹的中序走訪序列](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/binary_search_tree.assets/bst_inorder_traversal.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

中序走訪是「左、根、右」，BST 又滿足左 < 根 < 右，所以走訪時總是先碰到下一個最小的節點，**BST 的中序走訪序列是升序**。取得有序資料只要 O(n)，不用額外排序。

範例：根 4，左 2（孩子 1、3），右 6（孩子 5、7），中序得 1 2 3 4 5 6 7。

**易錯點**：條件是整串子樹，不是只比父子。根 5、左孩子 3、3 的右孩子 8：父子單看都合理，但中序得 3、8、5，不是升序，所以不是 BST。

```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int v) { val = v; }
}

void inorder(TreeNode node) {
    if (node == null) return;
    inorder(node.left);
    System.out.println(node.val);
    inorder(node.right);
}
```

### 這東西用在哪

- 寫程式：需要邊新增邊保持有序時選 BST；Java 的 TreeMap/TreeSet 底層是紅黑樹（自平衡 BST）。驗證 BST、找第 k 小的核心都是中序走訪。
- 產品端：排行榜、依價格排序的清單，背後常是「放進去就排好」的結構；依序列出全部資料的工作量跟筆數成正比（10 倍資料約 10 倍時間），但一次列幾百萬筆仍然太多，通常要分頁。

### LeetCode

[#230 Kth Smallest Element in a BST](https://leetcode.com/problems/kth-smallest-element-in-a-bst/)（Medium）

- 題意：給 BST 根節點與 k，回傳第 k 小的值。
- 解法：中序走訪，拜訪自己時計數加 1，等於 k 就記下答案並提早停止。
- 複雜度：時間 O(n)（最壞 k = n 要走完所有節點）；空間 O(h)（遞迴深度，歪斜時最壞 O(n)）。

```java
class Solution {
    private int count = 0;
    private int answer = 0;

    public int kthSmallest(
            TreeNode root, int k) {
        inorder(root, k);
        return answer;
    }

    private void inorder(
            TreeNode node, int k) {
        if (node == null) return;
        inorder(node.left, k);
        if (count >= k) return;
        count++;
        if (count == k) {
            answer = node.val;
            return;
        }
        inorder(node.right, k);
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Binary Search Tree | 二元搜尋樹 | 整串左子樹 < 根 < 整串右子樹的二元樹 |
| Root | 根節點 | 樹最上面、沒有爸爸的節點 |
| Subtree | 子樹 | 某節點底下延伸出的整串節點 |
| Inorder traversal | 中序走訪 | 左、根、右的拜訪順序 |
| Ascending order | 升序 | 由小到大 |
| Height | 樹高 h | 根到最底節點最長路徑的層數 |
