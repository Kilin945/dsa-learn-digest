## 平衡樹 AVL：BST 為什麼會退化、旋轉怎麼救回來 · 第 4 步

### Double Rotation: Left-Right and Right-Left

![先左旋後右旋](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/avl_tree.assets/avltree_left_right_rotate.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

圖中的失衡節點 3，只做一次左旋或一次右旋都無法恢復平衡。要先對 child 左旋，再對 node 右旋；順序不能顛倒。

![AVL 樹的四種旋轉情況](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/avl_tree.assets/avltree_rotation_cases.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

四種失衡情況依序對應：右旋、先左旋後右旋、先右旋後左旋、左旋。兩兩互為鏡像。

**為什麼單旋轉會失靈**：node 左重，但 child 自己右重（多出的份量在 grand_child 底下）。直接右旋只會把失衡換到另一邊。

**雙旋轉的做法**：LR 先對 child 左旋把彎折拉直，再對 node 右旋；RL 為鏡像。每次旋轉 O(1)，中序順序不變。

**怎麼決定**：

| node 平衡因子 | child 平衡因子 | 動作 |
|---|---|---|
| > 1 | >= 0 | 右旋 |
| > 1 | < 0 | LR：child 左旋 → node 右旋 |
| < -1 | <= 0 | 左旋 |
| < -1 | > 0 | RL：child 右旋 → node 左旋 |

```java
// bf = 左高 - 右高
static Node rebalance(Node node) {
  int f = bf(node);
  if (f > 1) {
    // 左邊太重
    if (bf(node.left) < 0) {
      // LR：先左旋 child
      node.left =
          leftRotate(node.left);
    }
    return rightRotate(node);
  }
  if (f < -1) {
    // 右邊太重
    if (bf(node.right) > 0) {
      // RL：先右旋 child
      node.right =
          rightRotate(node.right);
    }
    return leftRotate(node);
  }
  return node;
}
```

⚠ 最容易搞錯：只看 node 的平衡因子就決定方向；一定要再看 child。

### 這東西用在哪

- 程式面：Java 的 TreeMap／TreeSet 底層是紅黑樹，同屬自平衡 BST；需要排序＋快速查插刪＋範圍查詢時使用，避免有序輸入把普通 BST 變成 O(n)。
- 產品面：即時排行榜、價格區間篩選這類「持續新增又要維持排序」的功能背後常是平衡樹；一百萬筆約二十層，沒平衡的最壞情況是一百萬層。

### 動手寫 · LeetCode

[#1382 Balance a Binary Search Tree](https://leetcode.com/problems/balance-a-binary-search-tree/)（Medium）

中序走訪收集排序值，再取中間當根遞迴重建。時間 O(n)、空間 O(n)。

```java
class Solution {
  List<Integer> vals =
      new ArrayList<>();

  public TreeNode balanceBST(
      TreeNode root) {
    inorder(root);
    int last = vals.size() - 1;
    return build(0, last);
  }

  void inorder(TreeNode node) {
    if (node == null) return;
    // 中序：由小到大收集
    inorder(node.left);
    vals.add(node.val);
    inorder(node.right);
  }

  TreeNode build(int lo, int hi) {
    if (lo > hi) return null;
    // 取中間當根，左右各半
    int mid = (lo + hi) / 2;
    TreeNode n =
        new TreeNode(vals.get(mid));
    n.left = build(lo, mid - 1);
    n.right = build(mid + 1, hi);
    return n;
  }
}
```

### 術語表

- **Double Rotation（雙旋轉）**：連續兩次方向相反的旋轉。
- **Left-Right (LR)**：先對 child 左旋，再對 node 右旋。
- **Right-Left (RL)**：先對 child 右旋，再對 node 左旋。
- **Rebalance（重新平衡）**：依平衡因子挑出四種旋轉之一修復。
- **Balance Factor（平衡因子）**：左高減右高，AVL 要求在 -1 到 1。
