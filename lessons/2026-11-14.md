## 平衡樹 AVL：BST 為什麼會退化、旋轉怎麼救回來 · 第 3 步

### Left Rotation: the mirror of right rotation

**昨天右旋，今天左旋**：右旋治左邊太重；左旋治右邊太重（平衡因子小於 -1）。兩者互為鏡像，把右旋程式碼的 left、right 對調就是左旋。

**左旋的三個動作**：node 的右子節點 child 升為新根，node 降為 child 的左子節點。

**孫節點 grand_child 要改掛**：child 原本的左子節點 grand_child 改掛成 node 的右子節點。它比 node 大、比 child 小，所以放在這裡中序順序不變，仍是合法 BST。

> ⚠ 左旋、右旋的名字講的是 node 往哪個方向降，不是哪邊太重。右邊太重用左旋，左邊太重用右旋。

```java
TreeNode leftRotate(TreeNode node) {
    // child 是 node 的右子節點
    TreeNode child = node.right;
    // grandChild 是 child 的左子節點
    TreeNode grandChild = child.left;
    // node 降為 child 的左子節點
    child.left = node;
    // grandChild 改掛成 node 的右邊
    node.right = grandChild;
    // 先更新 node，再更新 child 的高度
    updateHeight(node);
    updateHeight(child);
    // child 成為這棵子樹的新根
    return child;
}
```

一句話：右邊太重就左旋，只改幾個指標，O(1)。

### 這東西用在哪

- 寫程式：Java 的 TreeMap/TreeSet 底層是紅黑樹，同樣靠旋轉維持平衡，所以 get、put 穩定 O(log n)。需要邊插入邊保持排序又要快查時，選自平衡的樹，不要用普通 BST。
- 產品端：即時排行榜、價格區間查詢這類功能背後常是自平衡的樹；一百萬筆約二十層，資料成長速度仍穩。可以問工程師：底層結構會不會自動維持平衡？

### 動手寫 · LeetCode

[#110 Balanced Binary Tree](https://leetcode.com/problems/balanced-binary-tree/)（Easy）

**題目在說什麼**：判斷二元樹是否平衡，即每個節點左右子樹高度差不超過 1。

**怎麼用今天學的東西解**：
1. 空節點高度為 0。
2. 遞迴算左右子樹高度（平衡因子的材料）。
3. 高度差絕對值大於 1 就回傳 -1。
4. 子樹回傳 -1 就一路往上傳。
5. 最後看根節點結果是否為 -1。

**複雜度**：時間 O(n)，每個節點只走訪一次；空間 O(h)，遞迴最深 h 層。

```java
class Solution {
    public boolean isBalanced(
            TreeNode root) {
        // 回傳 -1 代表整棵樹失衡
        return height(root) != -1;
    }

    // 回傳高度；失衡則回傳 -1
    private int height(TreeNode node) {
        if (node == null) return 0;
        int l = height(node.left);
        // 左子樹失衡，直接往上傳
        if (l == -1) return -1;
        int r = height(node.right);
        // 右子樹失衡，直接往上傳
        if (r == -1) return -1;
        // 平衡因子絕對值超過 1 就失衡
        if (Math.abs(l - r) > 1) {
            return -1;
        }
        // 回傳這棵子樹的高度
        return Math.max(l, r) + 1;
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
|---|---|---|
| Left rotation | 左旋 | 修復右邊太重：右子節點升為新根，失衡節點降為它的左子節點 |
| Mirror | 鏡像 | 左右對調後的樣子 |
| grand_child | 孫節點 | child 的子節點，左旋時搬到 node 右邊 |
| Balance factor | 平衡因子 | 左子樹高度減右子樹高度 |
| Red-black tree | 紅黑樹 | 另一種自平衡的樹，Java TreeMap 使用 |
