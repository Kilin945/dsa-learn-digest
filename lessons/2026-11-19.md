## 樹的經典題型：深度、直徑、最近共同祖先 LCA · 第 1 步

### Maximum Depth of a Binary Tree

**什麼是深度**：樹（tree）由節點（node）組成，最上面是根（root），沒有小孩的是葉（leaf）。二元樹每個節點最多左右兩個小孩。最大深度是從根到最遠葉所經過的節點數。

**遞迴的想法**：把問題交給左右子樹，公式為 `depth(node) = 1 + max(depth(左), depth(右))`。

**停止條件**：空樹（null）深度為 0，所以葉節點深度 = 1 + max(0, 0) = 1。

> ⚠ 深度可算節點數或邊數。LeetCode 104 算節點數（單根樹 = 1，空樹 = 0）。

```java
int depth(TreeNode node) {
    // 空樹：深度 0（停止條件）
    if (node == null) return 0;
    int l = depth(node.left);
    int r = depth(node.right);
    // 取較深的一邊，加上自己
    return 1 + Math.max(l, r);
}
```

### 這東西用在哪

- **工程師**：巢狀結構（資料夾、組織圖、留言串、DOM）算層數都用這個骨架；是直徑、LCA 的共同基礎。忘了 null 會 NPE，退化成鏈時遞迴過深可能 StackOverflowError。
- **產品端**：分類目錄、組織圖、留言串背後多半是樹；即時算整棵樹的時間跟節點總數成正比，資料大時應預先算好或限制層數。

### LeetCode [#104 Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/)（Easy）

1. root 為 null 回傳 0。
2. 遞迴取左子樹最大深度。
3. 遞迴取右子樹最大深度。
4. 回傳 1 + max(left, right)。

- 時間 O(n)：每個節點造訪一次。
- 空間 O(h)：遞迴堆疊最多疊到樹高；最壞 O(n)。

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        int left = maxDepth(root.left);
        int right = maxDepth(root.right);
        return 1 + Math.max(left, right);
    }
}
```
