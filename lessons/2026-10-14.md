## HashMap / HashSet：O(1) 查找的原理與代價 · 第 6 步

### Frequency Map: Counting with HashMap

**問題：數每樣東西出現幾次**

要統計 n 個元素各出現幾次，若對每個元素都把整份清單重掃一遍，是 O(n²)。這種需求叫頻率統計（frequency count）。用雜湊表，整份清單只要掃一輪就能統計完。

**做法：key 是東西，value 是次數**

像選舉唱票：每位候選人一欄（key），每唱到一票就在那欄加一筆（value + 1），新候選人從 0 開始。每看到一個元素：查目前次數（沒有就當 0）、加 1、放回去。

**Java 的兩種寫法**

- `getOrDefault(key, 預設值)`：key 不存在時回傳預設值而不是 null。
- `merge(key, 1, Integer::sum)`：不存在就放 1，存在就把舊值與 1 相加。

```java
Map<String, Integer> cnt =
    new HashMap<>();
for (String w : words) {
    // 沒出現過就當 0，再加 1
    cnt.put(w,
        cnt.getOrDefault(w, 0) + 1);
    // 等價的簡寫（擇一即可）
    cnt.merge(w, 1, Integer::sum);
}
```

**為什麼是 O(n)**

每次查＋放回平均 O(1)，n 個元素共 n 次，時間 O(n)。表裡只存不同的種類，k 種就 k 筆，空間 O(k)。

> ⚠ 最容易搞錯的地方：不要寫 `cnt.put(w, cnt.get(w) + 1)`。第一次遇到 w 時 get 回傳 null，拆箱（unboxing）時會丟出 NullPointerException。一定要用 getOrDefault 給 0，或用 merge。

**一句話：** 要數「每種東西出現幾次」，就開一個 HashMap，掃一輪、邊掃邊加 1，O(n) 搞定。

### 這東西用在哪

- 寫程式的人：題目或需求出現「出現幾次」「哪個最多」「有沒有重複」「兩邊內容是否一樣」，就想到計數器；詞頻、錯誤碼統計、anagram 都是這個模式。看到「對每個元素再掃一次整份資料」就該換成計數表，否則是 O(n²)。
- 產品端：後台的熱門關鍵字、各分類筆數、各錯誤次數，多半是掃一遍累加。工作量與總筆數成正比（資料多 10 倍，時間約多 10 倍）。記憶體則與種類數成正比，若幾乎每筆都不同（如訂單編號），表會跟資料一樣大，要擔心的是記憶體。可以問工程師：「這個統計是掃一遍就算完，還是每個類別都重掃一次？不同類別大概有幾種？」

### 動手寫 · LeetCode

[#387 First Unique Character in a String](https://leetcode.com/problems/first-unique-character-in-a-string/)（Easy）

**題目在說什麼**：給一個字串，找出第一個只出現過一次的字元的位置（從 0 開始），不存在就回傳 -1。

**怎麼解**：

1. 第一輪：掃整個字串，用計數器記下每個字元的次數。
2. 第二輪：依原順序再掃一次，查每個字元的次數。
3. 遇到第一個次數為 1 的字元就回傳其位置。
4. 都沒有就回傳 -1。

**複雜度**：時間 O(n)，兩輪各 n 步、每次查表平均 O(1)；空間 O(k)，表只存不同字元（這題小寫字母最多 26，可視為 O(1)）。

```java
class Solution {
    public int firstUniqChar(String s) {
        Map<Character, Integer> m =
            new HashMap<>();
        char[] a = s.toCharArray();
        int n = a.length;
        // 第一輪：統計每個字元次數
        for (char c : a) {
            m.merge(c, 1,
                Integer::sum);
        }
        // 第二輪：照原順序找次數 1
        for (int i = 0; i < n; i++) {
            if (m.get(a[i]) == 1) {
                return i;
            }
        }
        return -1;
    }
}
```

### 術語表

| 術語 | 中文 | 定義 |
| --- | --- | --- |
| Frequency Map | 頻率表／計數器 | 用 HashMap 記錄每種東西出現幾次：key 是東西，value 是次數 |
| getOrDefault | 取值或預設值 | key 存在回傳其值，不存在回傳指定的預設值 |
| merge | 合併 | key 不存在就放入給定值，存在就用指定規則合併新舊值 |
| Unboxing | 拆箱 | 把 Integer 物件還原成 int；物件為 null 時會丟 NullPointerException |
| Anagram | 同字母異序詞 | 字母種類與數量都相同、只是排列不同的字 |
