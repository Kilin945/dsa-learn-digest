## 陣列 Array 與動態陣列 ArrayList · 第 1 步

### 概念：Contiguous Memory & O(1) Access

Array（陣列）是一排資料，按順序一格接一格存放在記憶體裡，這種存放方式叫 contiguous memory（連續記憶體）。

因為連續，每個元素的記憶體位址可以用公式直接算出來：

```
位址 = 起始位址 + index × 每格大小
```

所以不管陣列有多少筆資料，用 index 存取任何一格永遠只需要「算一下、跳過去」，跟資料量無關 —— 這就是 O(1)（constant time，常數時間）。

比喻：一整排連號信箱，知道 1 號信箱位置和每格寬度，要找 87 號信箱不用從 1 號數過去，直接用公式算出位置走過去就好。

### 程式碼

```java
int[] scores = {85, 92, 77, 60, 99};

// 陣列在記憶體裡是「連續」排列的，
// 所以取第 i 格只要算位址，不用逐一尋找：
// 位址 = 起始位址 + i * 每格大小
int third = scores[2]; // 直接跳到第 2 格 → 77，O(1)
```

### 術語表

| 術語 | 定義 |
|---|---|
| Array（陣列） | 一排資料，按順序、一格接一格存放的資料結構 |
| Contiguous memory（連續記憶體） | 資料一格接一格放，中間沒有空隙 |
| Index（索引） | 標示「第幾格」的數字，Java 從 0 開始算 |
| Memory address（記憶體位址） | 資料實際存放在記憶體裡的「門牌號碼」 |
| O(1) constant time（常數時間） | 不管資料多寡，操作次數都固定不變 |
