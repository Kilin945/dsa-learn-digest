## Binary Tree 基礎：節點、深度與陣列表示法 · 第 3 步

### Array Representation of Any Binary Tree

**問題：空位被吃掉了**

昨天的公式（左子 2i+1、右子 2i+2、父節點 (i-1)/2）只在沒有空位的完美二元樹上成立。若層序走訪序列沒有記錄 None，我們無法知道 None 的數量與位置，同一串序列可以對應多種二元樹。

![層序走訪序列對應多種二元樹可能性](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/array_representation_of_tree.assets/array_representation_without_empty.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

**解法：空位也留一格**

在層序走訪序列中明確寫出所有 None，序列就能唯一表示一棵二元樹，公式也不會漂移。

![任意型別二元樹的陣列表示](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_tree/array_representation_of_tree.assets/array_representation_with_empty.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

```java
// 索引: 0  1  2    3   4  5  6
Integer[] tree =
    {1, 2, 3, null, 4, 5, 6};

static Integer left(
        Integer[] t, int i) {
    int l = 2 * i + 1;
    // 超出陣列，代表沒有這個孩子
    if (l >= t.length) return null;
    return t[l];
}
```

**特例：完全二元樹可以省略**

完全二元樹只有最底層可以不滿，且最底層從左到右連續排，所以 None 一定在層序序列的尾端，可省略不存。注意：一般的樹不能省略；而且樹越歪需要的 null 越多（只往右長的鏈，高度 h 時陣列長度 2^(h+1)-1）。

**這東西用在哪**

- 寫程式：樹接近完全時用陣列（省引用、記憶體連續，堆積即是如此）；樹很歪又常增刪時改用節點加指標。LeetCode 的 [1,2,3,null,4] 輸入格式就是寫出 null 的層序序列。
- 產品端：排行榜、任務排程這類「快速取最大／最急」的功能，背後常是陣列版完全二元樹，緊湊又省記憶體；但資料形狀變歪時空間可能暴增，可以問工程師「資料形狀會不會變歪」。

### LeetCode · [#958 Check Completeness of a Binary Tree](https://leetcode.com/problems/check-completeness-of-a-binary-tree/)（Medium）

**題目在說什麼**：判斷一棵二元樹是不是完全二元樹。

**解法步驟**：

1. 完全二元樹的層序序列中，None 一定在最尾端。
2. 用佇列做層序走訪，連空的子節點也放進佇列。
3. 取出 null 就記下 seenNull。
4. 之後若又取出非 null 節點，回傳 false。
5. 走完回傳 true。

**複雜度**：時間 O(n)，每個節點進出佇列一次；空間 O(n)，佇列最多裝一整層。

```java
class Solution {
  public boolean isCompleteTree(
      TreeNode root) {
    Queue<TreeNode> q =
        new LinkedList<>();
    q.offer(root);
    boolean seenNull = false;
    while (!q.isEmpty()) {
      TreeNode node = q.poll();
      if (node == null) {
        // 遇到空位，記下來
        seenNull = true;
      } else {
        // 空位後又出現節點，不完全
        if (seenNull) return false;
        // 連空的子節點也放進去
        q.offer(node.left);
        q.offer(node.right);
      }
    }
    return true;
  }
}
```

### 術語表

- **None / null（空值）**：表示這個位置沒有節點。
- **Level-order traversal（層序走訪）**：一層一層、每層由左到右讀出節點。
- **Complete binary tree（完全二元樹）**：只有最底層可以不滿，且最底層節點從左到右連續排；完美二元樹也算。
- **Queue（佇列）**：先進先出的容器，層序走訪靠它實作。
