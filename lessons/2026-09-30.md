## Stack 堆疊：後進先出、括號配對與單調堆疊 · 第 3 步

### 今日小步：Bracket Matching with a Stack

括號配對的核心觀察：每次遇到左括號，代表「開了一段還沒結束的範圍」；遇到右括號時，必須關閉的是**最後**打開的那個範圍——這正好對應堆疊的後進先出（LIFO）特性。

演算法：
1. 從左到右掃過字串。
2. 遇到左括號就 push 進堆疊。
3. 遇到右括號，pop 堆疊頂並比對是否為對應的左括號；不對或堆疊已空則不合法。
4. 掃完後堆疊必須剛好清空，才算合法。

這個「先開後關」的規則也出現在程式碼縮排、HTML 標籤解析、資料庫查詢巢狀括號等場景。

⚠ 最容易搞錯：只檢查過程中彈出是否對得上，卻忘了掃完後要確認堆疊「剛好清空」（例如 `"(()"` 過程中沒出錯，但結尾仍有未關閉的左括號，應判為不合法）。

```java
// 遇到左括號：推進堆疊
stack.push(c);

// 遇到右括號：彈出並比對
char top = stack.pop();
```

### 這東西用在哪

- **對工程師**：任何「巢狀、要對應著關閉」的合法性驗證（編譯器括號檢查、XML/HTML 標籤閉合、表達式求值前檢查）都適合用堆疊；只用計數器數左右括號數量會漏掉順序錯誤（例如 `([)]`），堆疊才抓得出來。
- **對產品端**：驗證使用者輸入格式（模板語法、程式碼片段）的功能背後常是堆疊在掃一遍；只需掃一次，資料量再大也是線性成長，效能瓶頸通常不在演算法本身。

### LeetCode #20 Valid Parentheses（Easy）

[https://leetcode.com/problems/valid-parentheses/](https://leetcode.com/problems/valid-parentheses/)

給一個只含 `()[]{}` 的字串，判斷括號是否正確配對、順序也對。

解法步驟：
1. 建立堆疊，從左到右掃字串。
2. 左括號 push；右括號時檢查堆疊是否為空，為空則 false。
3. pop 堆疊頂，比對是否為對應左括號，不對則 false。
4. 掃完後回傳堆疊是否為空。

複雜度：時間 O(n)（每字元最多 push/pop 各一次）；空間 O(n)（最壞全是左括號，全部入堆疊）。

```java
public boolean isValid(String s) {
    Deque<Character> stack =
        new ArrayDeque<>();
    String open = "([{";
    String close = ")]}";
    for (char c : s.toCharArray()) {
        int idx = open.indexOf(c);
        if (idx != -1) {
            stack.push(c);
            continue;
        }
        if (stack.isEmpty()) {
            return false;
        }
        char top = stack.pop();
        int topIdx =
            open.indexOf(top);
        char expected =
            close.charAt(topIdx);
        if (expected != c) {
            return false;
        }
    }
    return stack.isEmpty();
}
```

### 術語表

- **Bracket Matching 括號配對**：檢查一段內容裡的括號（或任何成對符號）是否每個都對應、順序正確。
- **Nested Structure 巢狀結構**：一層包著一層，內層必須先處理完外層才能處理完。
- **Valid Sequence 合法序列**：符合配對規則、掃完剛好清空的括號排列。
