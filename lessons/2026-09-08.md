## 空間複雜度：記憶體也要算，遞迴呼叫堆疊的隱藏成本 · 第 2 步

### 今日概念：Stack Frames: The Hidden Cost of Recursion

每呼叫一次函式，系統就會在呼叫堆疊（call stack）頂端建立一小塊空間——堆疊幀（stack frame），存放這次呼叫的參數、區域變數與返回位址；函式一 return，這塊空間就被釋放。

迴圈呼叫函式時，每次呼叫完立刻返回、堆疊幀立刻釋放，同一時間堆疊上最多只有一個堆疊幀，空間不會累積，是 O(1)。遞迴呼叫自己時，外層呼叫要等內層先返回才能繼續，堆疊幀只會往上疊，不會被提前收走。若遞迴深度為 n，最深的那一刻會同時存在 n 個還沒返回的呼叫，佔用 O(n) 的堆疊空間——即使時間複雜度跟迴圈一樣是 O(n)，空間複雜度可能不同。

⚠ 最容易搞錯的地方：只看時間複雜度、忽略遞迴深度，會誤以為遞迴和迴圈的空間開銷一樣。

```java
// 迴圈版：呼叫完立刻釋放，O(1)
void loop(int n) {
    for (int i = 0; i < n; i++) {
        function();
    }
}

// 遞迴版：n 層呼叫同時存在，O(n)
void recur(int n) {
    if (n == 0) return;
    recur(n - 1);
}
```

### 動手寫：[#206 Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/)（Easy）

遞迴反轉單向鏈結串列：遞迴深度等於串列長度 n，過程中會同時存在 n 個還沒返回的呼叫，時間 O(n)、空間 O(n)（堆疊幀），是今天概念的活教材。

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode newHead = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }
}
```

### 今日術語表

| 術語 | 定義 |
|---|---|
| Stack frame 堆疊幀 | 函式被呼叫時建立的一小塊空間，存放參數、區域變數與返回位址，return 後釋放 |
| Call stack 呼叫堆疊 | 所有還沒返回的函式呼叫依序疊起來的整體結構 |
| Recursion depth 遞迴深度 | 遞迴函式從第一次呼叫到最底層還沒返回為止，疊了幾層 |
| Stack overflow 堆疊溢位 | 遞迴太深、堆疊空間被佔滿超出系統限制，程式當掉 |

### 這東西用在哪

- 對寫程式的人：遞迴適合處理樹狀／巢狀資料，但輸入變大前要先估遞迴深度，深度等於 n 就要付出 O(n) 堆疊空間，太深會 stack overflow。
- 對產品端的人：功能「資料一大就變慢或掛掉」，可能是背後用了遞迴，資料量疊高呼叫記錄，跟資料庫效能無關，換寫法才能解。
