## Heap / PriorityQueue：完全二元樹、上浮下沉與 Top-K · 第 2 步

### Sift Up & Sift Down：新增與拿走元素後，堆積怎麼修好

![元素入堆積步驟](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_heap/heap.assets/heap_push_step1.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

入堆積（push）：先把新元素加到堆積底（陣列最後面），因為它可能比其他元素大，父子大小規則可能被破壞，所以要從插入節點往根節點修復。拿插入節點跟父節點比，插入節點更大就交換，重複到越過根節點或不用交換為止。這個由下往上的動作叫「上浮」（sift up）。

![堆積頂元素出堆積步驟](https://raw.githubusercontent.com/krahets/hello-algo/main/zh-hant/docs/chapter_heap/heap.assets/heap_pop_step1.png)

圖：[Hello 算法](https://www.hello-algo.com/) · CC BY-NC-SA 4.0

出堆積（pop）：不能直接刪陣列第一個元素（後面所有索引都會變動）。做法：

1. 交換堆積頂與堆積底（根節點與最右葉節點）。
2. 把堆積底從陣列刪掉（實際刪的是原本的堆積頂）。
3. 從根節點由上往下「下沉」（sift down）：跟兩個孩子比，與較大的孩子交換（大頂堆積），重複到越過葉節點或不用交換。

**複雜度**：完全二元樹高度約 log₂n，上浮與下沉最多走完一條樹高的路，所以 push、pop 都是 O(log n)。

**最容易搞錯**：下沉要跟「較大的孩子」換（大頂堆積）。小頂堆積（Java PriorityQueue 預設）則跟較小的孩子換。

```java
void siftUp(int[] h, int i) {
    while (i > 0) {
        int p = (i - 1) / 2;
        // 父親 >= 我，就不用再爬了
        if (h[p] >= h[i]) break;
        swap(h, p, i);
        i = p;
    }
}

void siftDown(int[] h, int n, int i) {
    while (true) {
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int max = i;
        // 找出 我、左、右 之中最大的
        if (l < n && h[l] > h[max])
            max = l;
        if (r < n && h[r] > h[max])
            max = r;
        // 我就是最大，不用再降了
        if (max == i) break;
        swap(h, i, max);
        i = max;
    }
}
```

**一句話**：push = 放最後再上浮、pop = 尾巴換到頭再下沉，都只走一條路，所以是 O(log n)。

### 這東西用在哪

- 寫程式：需求是「資料不斷進來、每次只要目前最大／最小的」就用堆積。新增與取最大都是 O(log n)，不用維持整份排序。注意 PriorityQueue 走訪時順序不是排序後的，remove(任意元素) 要先 O(n) 找。
- 產品端：緊急工單置頂、派單、排程這類功能多半是堆積。資料量變一萬倍，每次操作時間只約變三倍；但它只保證最頂端正確，若要完整排序清單需另外處理。可問工程師：「只要最上面那筆對，還是整份都要排好？」

### 動手寫 · LeetCode

[#1962 Remove Stones to Minimize the Total](https://leetcode.com/problems/remove-stones-to-minimize-the-total/)（Medium）

題目：有多堆石頭，做 k 次操作，每次挑最多的一堆，拿走一半（無條件捨去），剩 x - floor(x/2)。求最後石頭總數的最小值。

解法步驟：

1. 用大頂堆積存所有堆（offer 會上浮）。
2. 重複 k 次：poll 取最大一堆（下沉）。
3. 算 x - x/2，offer 放回（上浮）。
4. 最後加總堆積內所有數字。

複雜度：時間 O((n + k) log n)，因為 n 次放入與 k 輪 poll + offer 各 O(log n)；空間 O(n)，堆積存全部 n 堆。

```java
class Solution {
    public int minStoneSum(
            int[] piles, int k) {
        // 大頂堆積：最大的在頂端
        PriorityQueue<Integer> pq =
        new PriorityQueue<>(
        Collections.reverseOrder());
        for (int p : piles) {
            pq.offer(p);
        }
        while (k-- > 0) {
            // 取出最大的一堆（下沉）
            int x = pq.poll();
            // 剩 x - x/2（整數除法）
            // 放回堆積（上浮）
            pq.offer(x - x / 2);
        }
        int sum = 0;
        for (int p : pq) {
            sum += p;
        }
        return sum;
    }
}
```

### 術語表

| 術語 | 白話定義 |
|---|---|
| Sift Up 上浮 | 新元素放最後，跟父親比，比父親大就交換往上，直到不用換或到根 |
| Sift Down 下沉 | 從根開始跟較大的孩子交換往下，直到比孩子都大或到葉節點 |
| Heapify 堆積化 | 修復父子大小規則的動作統稱，上浮與下沉都屬於它 |
| Push / Pop 入堆積／出堆積 | 新增一個元素／拿走堆積頂元素 |
| Leaf node 葉節點 | 沒有孩子的節點，位在最底層 |
| Priority Queue 優先佇列 | 每次取出優先權最高的元素；Java PriorityQueue 用堆積實作 |
