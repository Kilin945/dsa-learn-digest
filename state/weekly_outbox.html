這週我們學了兩大塊：雜湊衝突的兩種處理法、二元樹（基礎、形狀、走訪）。下面 7 題請先自己想，再看信末解答。前 4 題是概念與應用題（不用寫程式），後 3 題是實作與複雜度題。

小提醒：二元樹＝每個節點最多有左、右兩個子節點的資料結構；雜湊表＝用「鑰匙算出位置」來快速存取資料的表格，一個位置叫一個「桶」；衝突＝兩筆資料算出同一個桶。

Q1（概念）

兩筆資料被分到同一個桶（衝突）時，「鏈結法」和「開放定址」各是怎麼處理的？請用生活比喻說明（例如：同一格置物櫃放不下時怎麼辦）。

Q2（概念）

你要選一種衝突處理法：資料常常被刪除，而且資料量很難預估、可能比桶數還多。該選哪一種？為什麼？另一種在這個情境會出什麼問題？（提示：負載因子＝資料筆數 ÷ 桶數，代表表格有多擠。）

Q3（概念）

想把公司的組織圖、或「是／否」決策流程，存成二元樹。為什麼說二元樹的「形狀」會決定查找快不快？什麼樣的形狀最快、什麼樣的形狀最糟？「平衡二元樹」是用來防止什麼事？

Q4（概念）

情境 A：你要「一層一層」列出組織圖，先印所有主管，再印所有直屬部下。情境 B：你要「一路走到底」，先把某條線的人看完才換下一條。這兩個情境分別該用 BFS（層序走訪）還是 DFS（深度優先走訪）？BFS 靠什麼工具（資料結構）來幫忙？

Q5（實作）

完美二元樹以「層序」存進陣列（陣列＝一排編了號的格子，編號從 0 開始）。索引 i 的左子、右子、父節點索引各是多少？請算出索引 5 的父節點與它的兩個子節點索引。

Q6（實作）

有一棵樹：根是 1，1 的左子是 2、右子是 3，2 的左子是 4、右子是 5，3 沒有子節點。請分別寫出前序、中序、後序走訪的結果。（前序＝先訪問當前節點再左再右；中序＝左、當前、右；後序＝左、右、當前。）

另外，這棵樹若以層序存進陣列，需要把空位寫成 null，請寫出完整陣列。

Q7（實作與複雜度）

(a) BFS 分層時，為什麼每一輪開始要先記下佇列目前的 size？(b) BFS 與遞迴 DFS 的時間複雜度各是多少？空間複雜度在「最壞情況」下各由什麼決定？(c) 一棵有 n 個節點、退化成一條線（每個節點只有一個子節點）的樹，遞迴 DFS 的空間是多少？

—— 解答 ——

Q1：鏈結法＝同一個桶後面再「掛一串」（像同一格置物櫃用掛鉤串著多件東西），衝突的資料都留在該桶外面串起來。開放定址＝這格被占了就往旁邊找空格（像停車位滿了就往下一個空位停），所有資料都擠在桶內。

Q2：選鏈結法。刪除只要從串中拿掉一筆即可；負載因子可以超過 1（資料比桶多也行，只是串變長）。開放定址刪除時要留「墓碑」（標記「這裡以前有東西」，避免後面的搜尋斷掉），而且負載因子不能超過 1、越擠越慢，資料量難預估時容易塞爆。

Q3：形狀決定要走幾步。完美樹（每層都填滿）高度約 log n，走到底很快；最糟是退化成一條線（像鏈結串列），高度變 n，查找變 O(n)。平衡二元樹要求每個節點左右子樹高度差不超過 1，用來防止退化。

Q4：A 用 BFS（一層一層），靠「佇列」（先進先出的排隊，像排隊買票）來做。B 用 DFS（先走到盡頭再回頭）。

Q5：左子 2i+1、右子 2i+2、父 (i−1)/2（取整數）。i=5：左子 11、右子 12、父 (5−1)/2=2。

Q6：前序：1,2,4,5,3；中序：4,2,5,1,3；後序：4,5,2,3,1。層序陣列：[1, 2, 3, 4, 5]（這棵樹是完全二元樹，空位都在尾端，所以可以不存；若 3 有子節點缺失在中間則要寫 null）。補充：索引 5、6 是 3 的子節點位置，若要明確表示就是 [1,2,3,4,5,null,null]，尾端的 null 可省略。

Q7：(a) 因為佇列在處理過程中會不斷加入下一層的節點，先記下 size 才知道「這一輪該處理幾個」＝剛好一層，才能分層。(b) 兩者時間都是 O(n)（每個節點只看一次）。BFS 最壞空間取決於「最寬那一層的節點數」，最壞 O(n)；遞迴 DFS 最壞空間取決於「樹高」（遞迴呼叫堆疊深度）。(c) 退化成一條線時樹高＝n，所以遞迴 DFS 空間是 O(n)。
